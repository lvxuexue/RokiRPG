## 5. 装备生成算法

### 5.1 掉落装备生成流程

```
1. 确定阶位（根据怪物等级区间）
2. 确定品质（根据掉落表权重roll）
3. 生成基础属性（在阶位范围内随机）
4. 生成主要词条（品质决定数量，从槽位允许池中随机）
5. 生成次要词条（品质决定数量，从全局池中随机）
6. 特殊词条判定（金色20%/暗金60%/红色100%从特殊池抽取）
7. 专属词条判定（仅红色品质，从专属池随机）
8. 词条数值波动（在范围内随机±10%）
9. 生成装备名（前缀[品质] + 阶位名 + 部位名）
   例：「仙品·赤金飞剑」「传说·混沌圣衣」
```

### 5.2 槽位词条池限制

| 槽位 | 可出主要词条 | 不可出次要词条 |
|------|-------------|---------------|
| 武器 | ATK%、AP%、CRIT%、CRIT DMG%、属性伤害% | 受伤减免 |
| 头部 | DEF%、HP% | 移速 |
| 衣服 | DEF%、MR%(特殊) | 掉落率 |
| 鞋子 | SPD% | 反弹 |
| 项链 | HP%、MP%、属性伤害% | — |
| 戒指1 | CRIT%、AP% | 减CD |
| 戒指2 | CRIT DMG%、ATK% | MP消耗- |
| 腰带 | HP%、DEF% | 属性穿透 |

### 5.3 词条数值波动

每条词条生成时在基础范围的 **90%~110%** 之间随机波动，同一件装备的词条波动独立计算。

## 9. 装备洗炼与附魔

### 9.1 洗炼

```
洗炼规则：
  1. 消耗洗炼石×1
  2. 可锁定1-3条词条（消耗锁定符，锁定1条=1符，2条=3符，3条=6符）
  3. 未锁定词条全部重新随机
  4. 洗炼后词条数值在范围内重新随机
  5. 品质不变、强化等级不变
  6. 每次洗炼累计"洗炼次数"，每10次保底出1条满值词条
```

### 9.2 附魔

```
附魔系统（元婴期解锁）：
  - 消耗附魔石 + 灵石
  - 给装备附加临时附魔效果（持续72小时/到下次附魔）
  - 附魔效果池：
    ├── 攻击附魔：ATK+5%、暴击伤害+10%、属性伤害+15%
    ├── 防御附魔：DEF+5%、HP+8%、受伤减免+3%
    └── 特殊附魔：经验+10%、掉落率+8%、移速+10%
  - 高级附魔石（稀有掉落）可附加2条效果
```

### 11.6 构建型装备保底机制（v1.1新增）

```
保底规则（全局）：
  每击杀对应稀有怪/Boss N次，第N+1次必定掉落构建型装备

  N值设定：
    筑基期构建型装备：每20次
    金丹期构建型装备：每25次
    元婴期构建型装备：每30次
    化神期构建型装备：每35次

渐进掉率规则（配合保底）：
  每击杀对应怪物5次，掉率+2%（可叠加，触发保底后重置）
  示例：基础掉率5% → 10次后7% → 20次后13% → 若仍未掉落→第21次必掉

显示优化：
  怪物图鉴中显示"已击杀X次，当前掉率Y%，保底倒计时Z次"
```

### 11.7 构建型装备锻造配方（v1.1新增）

## 12. 法宝系统（基础）

### 12.1 法宝槽位

法宝（第9槽）在金丹期(Lv41)解锁，是战斗中的主动技能装备。法宝拥有独立的技能CD体系，与角色技能并行运作。

### 12.2 法宝品质与阶位

| 品质 | 技能倍率 | 技能数 | 冷却时间 | 获取途径 |
|------|:---:|:---:|:---:|------|
| 凡品(白) | 100% | 1 | 60s | 任务保底（聚灵珠） |
| 良品(绿) | 130% | 1 | 50s | 炼制/精英怪掉落 |
| 上品(蓝) | 170% | 1 | 40s | 炼制/Boss掉落 |
| 极品(紫) | 220% | 1-2 | 35s | 炼制（金丹期+）/稀有掉落 |
| 仙品(金) | 280% | 2 | 30s | 炼制（元婴期+）/奇遇 |
| 圣品(暗金) | 350% | 2-3 | 25s | 炼制（化神期）/隐藏Boss |
| 传说(红) | 500% | 3 | 20s | 唯一获取（终局条件） |

### 12.3 首个法宝：聚灵珠

金丹期主线「金丹大道」在宗门宝库领取（免费，仅1次）：

| 字段 | 值 |
|------|-----|
| 名称 | 聚灵珠 |
| 品质 | 凡品(白) |
| 技能 | 「灵力爆发」— 消耗当前MP的30%，造成AP×200% AOE伤害（半径6m），CD 45s |
| 引导 | 领取后触发教程：①装备法宝到法宝槽 ②战斗中测试灵力爆发 ③介绍法宝炼制系统 |

### 12.4 法宝炼制

法宝炼制在宗门"炼器阁"进行（金丹期解锁）：

**炼制配方**：

| 法宝品质目标 | 主材料 | 辅料 | 灵石 | 成功率（基础） |
|:---:|------|------|:---:|:---:|
| 凡品→良品 | 妖兽内丹(灵)×2 | 灵晶碎片×3 | 2,000 | 70% |
| 良品→上品 | 妖兽内丹(灵)×3 | 上品灵石×5 | 5,000 | 55% |
| 上品→极品 | 金丹级内丹×2 | 上品灵石×8 | 10,000 | 40% |
| 极品→仙品 | 元婴级内丹×2 | 仙灵石×3 | 25,000 | 25% |

附加灵石可提升成功率（下品+5%/中品+10%/上品+15%）。失败不损失法宝，仅消耗材料。

### 12.5 法宝共鸣

当法宝与角色主修元素相同时，触发共鸣加成：

| 共鸣条件 | 效果 |
|----------|------|

| 法宝元素=副修战斗功法元素 | 法宝技能伤害+15% |
| 法宝品质≥紫色 | 法宝技能附加该元素debuff（灼烧/中毒/冰冻/麻痹/诅咒对应元素） |

## 13. 本命法宝系统（基础）

### 13.1 觉醒条件

本命法宝（第10槽）在元婴期(Lv61)解锁。与普通法宝不同，本命法宝通过"本命炼制"觉醒（非掉落/锻造）：

```
元婴期主线「元婴觉醒」引导步骤：
  1. 达到Lv61 → 触发自动对话"你感到体内元婴躁动..."
  2. 在宗门"元婴殿"消耗本命精血×1（任务获得）+ 灵晶×10 + 灵石×5000
  3. 炼制成功 → 获得「本源之种」（凡品本命法宝）
  4. 本源之种被动效果：战斗中每60s自动获得HP×10%吸收盾
```

### 13.2 本命法宝成长

本命法宝无法更换——它是角色绑定的唯一装备，通过"元婴滋养"提升品质：

| 滋养等级 | 消耗 | 品质提升 | 新增效果 |
|:---:|------|:---:|------|
| 1→2 | 元婴级内丹×2 + 灵石×20,000 | 白→绿 | 护盾量+5% |
| 2→3 | 元婴级内丹×3 + 仙灵石×5 + 灵石×50,000 | 绿→蓝 | 解锁主动技「元婴出窍」（5s内伤害+30%, CD 180s） |
| 3→4 | 化神级内丹×2 + 圣灵石×5 + 灵石×100,000 | 蓝→紫 | 主动技持续时间+2s |
| 4→5 | 化神级内丹×3 + 天道碎片×3 + 灵石×300,000 | 紫→金 | 解锁被动「不灭元婴」：受到致命伤害时元婴替死1次(CD 600s) |

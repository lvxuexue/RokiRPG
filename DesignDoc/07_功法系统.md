## 1. 功法架构

```
功法体系（同时装备：1主修+2副战+1身法+1秘术=5部）

├── 修炼功法（主功法）— 决定修炼速度、基础属性成长
│   槽位：1个
│   影响：exp获取速率、每级属性成长、灵力恢复速度
│
├── 战斗功法（副功法）— 提供被动战斗效果、战斗技能
│   槽位：2个（筑基解锁第2槽）
│   影响：战斗中被动效果、特定条件触发技能
│
├── 身法功法 — 影响SPD、闪避、先手
│   槽位：1个
│   影响：ATB填充速度、闪避率、先手判定、逃跑率
│
└── 秘术功法 — 特殊能力/生活技能加成
    槽位：1个
    影响：炼丹/锻造/采药/探索/神识/交易加成
```

### 1.1 槽位解锁时机

| 槽位 | 解锁时机 | 说明 |
|------|----------|------|
| 主修槽(修炼) | 初始（Lv1） | 吐纳术(白)随角色创建获得 |
| 战斗槽① | 初始（Lv1） | 基础剑法(白)随初始技能倾向获得 |
| 战斗槽② | 初始（Lv1） | 空槽——通过初始引导任务获得第2部战斗功法 |
| 身法槽 | 初始（Lv1） | 空槽——需通过主线任务「初入江湖」获得疾风步(绿) |
| 秘术槽 | 筑基期（Lv21） | 突破后自动解锁，首次进入坊市触发"秘术初窥"引导任务 |

设计意图：
- Lv1-20 4槽（修炼+双战斗+身法）→ 前期即有双战斗功法组合
- Lv21 5槽全解锁 → 筑基突破不仅是属性飞跃，也是功法系统的完整体验
- 身法槽初始空置是有意设计——引导玩家完成第一个任务获取疾风步
- 【v1.1调整】初始战斗槽位从1个增至2个，提升炼气期Build深度

## 4. 功法参悟系统（完善）

### 4.1 参悟流程

```
参悟步骤：
  1. 选择已装备的功法
  2. 消耗「悟道石」×1 + 灵石
  3. 等待参悟时间（可用灵石加速，最多加速80%）
  4. 参悟判定：
     成功率 = 基础成功率 × (1 + 悟性/150) × 品质系数

品质系数：
  白/绿：1.5  蓝：1.2  紫：1.0  金：0.8  暗金：0.6  红：0.4

参悟失败：
  - 悟道石消耗不返还
  - 获得「参悟心得」×1（累积可用于下次参悟+10%成功率）
  - 连续失败3次，第4次必成功

参悟成功：
  - 功法层数+1
  - 解锁对应层数效果
  - 若达到隐藏效果层数 → 随机解锁1个隐藏效果
```

### 4.2 悟道石获取途径（新增）

```
悟道石是功法参悟的核心资源，获取途径如下：

  日常获取（稳定来源）：
    - 日常任务奖励：2-3个/天
    - 宗门每日供奉：2个/天（筑基+宗门）
    - 分解满层功法：返还50%已消耗的悟道石
    - 灵石商店：3000灵石/个（每周限购8个）

  战斗获取（随机来源）：
    - Boss掉落：2-3个/次（80%概率）
    - 精英怪掉落：1个/次（25%概率）
    - 稀有怪掉落：2个/次（50%概率）
    - 秘境宝箱：1-3个/箱（50%概率）

  其他来源：
    - 奇遇事件：5-10个（单次奖励）
    - 签到奖励：1-2个/周
    - 灵石商店：3000灵石/个（每周限购10个）

  预期获取速率（v1.1调整后）：
    正常游玩：约4-8个/小时（含战斗掉落+日常均摊）
    勤奋farm：约10-14个/小时（专刷Boss+精英）
    
  以紫色功法满层(7层)需11个为例：正常1.5-3小时可满层
  以金色功法满层(8层)需17个为例：正常2-4.5小时可满层（v1.1降低）
  以红色功法满层(9层)期望需170个：约20-45小时（终局长线目标）
```

### 4.3 隐藏效果池

功法达到隐藏层数时，从以下池中随机抽取（可消耗「悟道茶叶」重新随机）：

  - 特定属性成长+15%
  - 灵力恢复速度+30%
  - 突破成功率+10%
  - 获得灵力护盾(战斗中每60s自动获得)

战斗功法隐藏池：
  - 对Boss伤害+15%
  - 暴击伤害+25%
  - 技能CD-10%
  - 击杀敌人回复20%HP/MP
  - 攻击附加随机元素伤害

身法功法隐藏池：

## 5. 功法组合共鸣

### 5.1 同源共鸣

装备同一来源/宗门的功法触发额外加成：

| 共鸣条件 | 效果 |
|----------|------|
| 主修+副战同元素 | 该元素伤害+20%，对应抗性+10% |
| 主修+副战+身法同元素 | 该元素伤害额外+10% → 累计+30%，该元素终极技CD-15% |
| 主修+身法同宗门 | 修炼速度+10% |
| 2部副战为同品质 | 副战效果+15% |
| 全5部同品质 | 全属性+10% + 全抗+10% |
| 全5部金+品质 | 全属性+25% + 全抗+20% + 「万法归宗」光环 |

**元素共鸣说明**：元素标签让玩家可以主动追求同元素功法共鸣（单元素Build获得高达+30%元素伤害），也可以选择跨元素通用功法获得更灵活的面板属性。两条路线通过共鸣系统获得了差异化奖励。

### 5.1.1 功法参悟转移（新增）

```
替换功法时保留部分参悟进度：

  转移规则：
    1. 在宗门"传功长老"处操作
    2. 消耗灵石：旧功法品质×1000（白1000→红7000）
    3. 转移比例：旧功法已参悟层数的50%→新功法
       例如：旧功法5层满层→新功法直接获得2层参悟
    4. 新功法品质不能超过旧功法2阶以上
       （白→蓝OK，白→紫不行）
    5. 旧功法保留但层数清零（可重新参悟）
    6. 隐藏效果不转移（需在新功法上重新解锁）
```
     
### 5.2 功法传承

```
传承系统（元婴期解锁）：
  - 可将已参悟的功法刻录为「传承玉简」
  - 传承玉简可给新角色使用（NG+ / 小号）
  - 刻录消耗：大量灵石 + 功法层数清零
  - 新角色使用玉简 → 直接获得该功法(1层)
  - 传承玉简可交易(游戏内灵石交易)
```

---

### 5.3 闪避溢出转化（新增）

```
当角色闪避率超过40%硬上限时，溢出部分自动转化：

  转化规则：
    每溢出1%闪避 → 转化为0.5%暴击率
    每溢出1%闪避 → 转化为0.3% ATK（两项并行）

  示例：暗修闪避流 62% - 40% = 22%溢出
    → 额外获得：暴击率+11%，ATK+6.6%

  设计意图：闪避流后期不会因硬上限而浪费属性，
           溢出转化收益控制在边际递减区间，
           不会催生"强行堆闪避"的极端Build。
```

### 5.4 功法元素自适应（新增）

```
部分通用定位但绑定特定元素的功法，增加"自适应"标签：

  自适应规则：
    标注"自适应"标签的功法 → 元素加成自动匹配角色灵根主属性
    自适应加成 = 原元素加成的70%（取整）

  适用功法（示例）：
    纯阳功(蓝)：火伤+28% → 金灵根剑修装备时→金伤+20%
    焚天诀(金)：火伤+40% → 暗灵根暗修装备时→暗伤+28%

  仅对约3-4个"通用定位但绑定特定元素"的功法添加自适应标签，
  不全面铺开，保留"同元素功法共鸣"作为更优选择。
```

### 1.2 修复原则

```
1. 最小改动原则：优先调数值而非加机制，只在数值无法解决时才引入新机制
2. 不破坏核心循环：所有改动必须符合"探索→战斗→养成→挑战"的核心循环
3. 增量交付：先修P0/P1（修好后玩家就能明显感知改善），再迭代P2/P3
4. 数据可逆：所有数值改动保留原始值作为注释，方便回滚对比
```

## 2. 功法系统完善方案

### 2.1 功法槽位节奏优化（问题①）

**现状**：Lv1-20期间战斗功法只有1个槽位，前期Build深度不足。

**方案**：

```
调整前：
  Lv1初始：修炼1 + 战斗1 + 身法0(任务后1) = 2→3槽
  Lv21筑基：修炼1 + 战斗2 + 身法1 + 秘术1 = 5槽

调整后：
  Lv1初始：修炼1 + 战斗2 + 身法0(任务后1) = 3→4槽
  Lv21筑基：修炼1 + 战斗2 + 身法1 + 秘术1 = 5槽（不变）
```

**设计理由**：初始多给1个战斗功法槽位，让玩家在炼气期就能体验双战斗功法的组合乐趣。筑基期5槽保持不变，终局不受影响。

**实现**：修改 `02_角色系统.md` 角色创建流程，初始赠送2个战斗功法（基础剑法 + 任意可选1个白/绿战斗功法）。

---

### 2.2 功法数值平衡（问题②⑤⑥⑦⑧）

#### 2.2.1 九天剑典数值修正（问题⑤）

**现状**：金丹期九天剑典(紫) ATK+18%，暴击率+10% — 不如筑基期天罡剑诀(蓝) ATK+22%，剑技+35%。

**方案**：

```
九天剑典(紫) 调整：
  原：ATK+18%，暴击率+10%
  新：ATK+25%，暴击率+8%，暴击伤害+20%
  
满层效果：
  原：ATK+18%，暴击率+10%，隐藏:剑阵连击
  新：ATK+25%，暴击率+8%，暴伤+20%，隐藏:剑阵连击
```

**设计理由**：暴击率从10%微降至8%避免溢出，增加暴伤+20%让金丹期剑修有明显成长感知，ATK从+18%提升至+25%确保紫色功法确实强于蓝色。

#### 2.2.2 焚天战诀效果修正（问题⑥）

**现状**：击杀灼烧目标→火系CD-3s，火球术CD仅2.5s，无限火球。

**方案**：

```
焚天战诀(金) 调整：
  原：击杀灼烧目标→火系技能CD-3s
  新：击杀灼烧目标→火系技能CD-1.5s（内置CD: 每4s最多触发1次）
```

**设计理由**：CD-1.5s + 内置4s冷却的双重限制，将火球术从"无限释放"修正为"每4s可额外释放1次"，输出提升约35-45%（从失衡的无限释放修正为可控爆发）。

#### 2.2.3 混沌战体触发率修正（问题⑦）

**现状**：受击5%概率时停1s，战斗中几乎不可感知。

**方案**：

```
混沌战体(暗金) 调整：
  原：受击5%概率时停1s
  新：受击10%概率时停1s（内置CD: 每15s最多触发1次）
```

**设计理由**：触发率翻倍至10%，但加上内置CD防止高频触发。在40分钟Boss战中，期望触发约6-8次，每次时停可多打1-2个技能，综合输出提升约10-15%，感知明显但不失衡。

#### 2.2.4 闪避溢出转化机制（问题⑧）

**现状**：闪避流后期闪避率62%，超过40%硬上限，溢出22%完全浪费。

**方案**：新增溢出转化规则

```
闪避溢出转化（新增全局规则）：
  当闪避率超过40%硬上限时：
    每溢出1%闪避 → 转化为0.5%暴击率
    每溢出1%闪避 → 转化为0.3% ATK（两项并行，非二选一）

示例：
  暗修闪避流 62% - 40% = 22%溢出
  → 额外获得：暴击率+11%，ATK+6.6%
  
  溢出收益控制在边际递减区间，不会催生"强行堆闪避"的极端Build。
```

#### 2.2.5 功法元素匹配优化（问题②）

**现状**：部分功法元素加成与角色不匹配（如纯阳功火伤+28%对剑修无用）。

**方案**：为部分通用型功法增加"元素自适应"机制

```
新增功法属性：自适应标签

适用功法（示例）：
  纯阳功(蓝)：火伤+28% → 主属性元素伤害+20%（自适应）
  混元功(蓝)：全属性+15%（不变，本身已是通用）

自适应规则：
  功法标注"自适应"标签 → 元素加成自动匹配角色灵根主属性
  例如：金灵根剑修装备纯阳功 → 金伤+20%（替代火伤+28%）
  自适应加成 = 原加成的70%取整（避免自适应过强）
```

仅对3-4个"通用定位但绑定特定元素"的功法添加自适应标签，不全面铺开。

### 2.3 功法参悟经济优化（问题③⑮）

**现状**：金色功法参悟成本高达75000灵石+36悟道石，金丹期玩家需farm约19小时仅灵石部分。

**方案**：

| 调整项 | 原值 | 新值 | 降幅 |
|--------|------|------|------|
| 金色功法灵石消耗(满层) | 75,000 | 50,000 | -33% |
| 金色功法悟道石消耗(满层) | 36 | 30 | -17% |
| 暗金功法灵石消耗(满层) | 150,000 | 100,000 | -33% |
| 暗金功法悟道石消耗(满层) | 45 | 38 | -16% |
| 红色功法灵石消耗(满层) | 500,000 | 350,000 | -30% |

**配合措施**：增加悟道石日常获取
- 宗门每日供奉：1个/天 → 2个/天
- 日常任务奖励：1-2个/天 → 2-3个/天
- 灵石商店限购：5个/周 → 8个/周

**预期效果**：金丹期金色功法farm时间从19小时降至约12小时，仍在合理肝度范围内。

### 2.4 太上忘情道修正（问题④）

**现状**：伤害+50%，无法用回复技。实际伤害提升约35%，死亡次数增加3倍，收益不如预期。

**方案**：

```
太上忘情道(暗金) 调整：
  原效果：
    修炼+70%，伤害+50%，无法使用回复技能

  新效果：
    修炼+70%，伤害+35%
    每场战斗首次受致命伤时：锁定HP为1，获得"忘情"状态（无敌3s+伤害+50%），
    忘情状态结束后恢复30%HP。每场限1次。
    仍无法使用回复技能。
```

**设计理由**：
- 伤害加成从+50%降至+35%（与其他暗金修炼功法对齐）
- 新增"忘情"被动 —— 作为"无法回复"的补偿，提供一次免死爆发机会
- 将惩罚从"纯负面"转化为"高风险高回报"的可控机制
- 整体收益：稳定+35%伤害 + 每场一次免死爆发窗口 ≈ 符合暗金功法的价值预期

## 3. 丹药系统完善方案

### 3.1 丹毒系统优化（问题⑨）

**现状**：修炼丹每日5颗，丹毒累积20点/天，自然衰减10点/天，净+10点/天，8天后触达80点阈值。

**方案**：

```
修炼丹丹毒下调：
  小聚灵丹：2点 → 1点
  聚灵丹：  3点 → 2点
  大聚灵丹：4点 → 3点
  仙聚丹：  5点 → 4点
  混沌丹：  6点 → 5点

丹毒自然衰减提升：
  原：10点/天
  新：15点/天（修炼状态下20点/天）
```

**预期效果**：正常服用5颗大聚灵丹 = 15点丹毒 - 15点自然衰减 = 0净增。只有额外服用属性丹才会累积丹毒，日常修炼丹使用无压力。

### 3.2 回复丹消耗优化（问题⑩）

**现状**：天道意志Boss战40-50分钟，消耗大回灵丹×40，材料farm压力巨大。

**方案A（推荐）**：降低材料需求 + 提升回复效果

| 丹药 | 原材料需求 | 新材料需求 | 原效果 | 新效果 |
|------|----------|----------|--------|--------|
| 大回灵丹 | 仙灵草×5 | 仙灵草×3 | 回复40%HP | 回复40%HP |
| 仙回丹 | 仙药×5 | 仙药×3 | 回复45%HP | 回复45%HP+15%MP |
| 圣灵丹 | 圣药×5 | 圣药×3 | 回复50%HP | 回复50%HP+20%MP |

**方案B（配合）**：终局Boss战斗中加入"补给阶段"

```
终局Boss（天道意志/上古魔帝/堕落真仙）新增机制：
  每打掉25% HP → 触发"天道震荡"
    - Boss进入3秒硬直
    - 玩家自动回复30%HP/MP
    - 回复丹战斗CD重置
  相当于将50分钟战斗拆分为4个约12分钟的段落，
  每个段落之间有自然补给窗口。
```

**推荐**：方案A + 方案B同时实施。方案A降低farm压力，方案B改善战斗节奏感。

### 3.4 渡劫系统优化（问题⑪）

**现状**：渡劫小游戏练习成本高（消耗突破材料），失败冷却24小时。

```
   新增：劫灰×2 → 可兑换"渡劫心得"（下次渡劫落雷速度-15%）
```

## 4. 角色平衡完善方案

### 4.1 问题根源分析

评估报告揭示了角色平衡的核心矛盾：

```
输出型角色（剑修/法修/暗修）：
  有明确的伤害放大机制（暴击/元素反应/诅咒爆发）
  → 功法+丹药+装备的叠乘效果 → 输出膨胀

坦克/治疗型角色（体修/医修）：
  防御/治疗在单机模式下存在"天花板效应"
  → 生存已经过剩，输出没有放大渠道
  → 战斗时间被拉长，体验单调
```

**核心解决思路**：为体修和医修提供"防御/治疗→输出"的转化通道，而不是简单粗暴地加ATK。

### 4.4 Build平衡：暴击流 vs 攻速流（问题⑫）

**现状**：暴击流期望205%，攻速流期望140%，差距47%。

**根源**：暴击流有3个乘区叠加（暴击率×暴伤×ATK加成），攻速流只有1个乘区（攻击频率）。

**方案**：

```
1. 新增攻速收益被动「疾风之势」（筑基期，通用被动）
   效果：SPD每提升10%，伤害+3%
   满SPD+100%时 → 伤害+30%
   
   这为攻速流增加了一个新的独立乘区。

2. 暴击伤害上限调整
   原：暴击伤害硬上限400%
   新：暴击伤害硬上限350%
   
   限制暴击流后期膨胀空间。

3. 暴击率溢出惩罚
   原：暴击率硬上限80%
   新增：暴击率超过70%后，每1%暴击率仅提供0.7%等效暴击率
   （边际递减，80%硬上限不变但接近上限时收益递减）
```

**调整后对比**：

| Build | 调整前期望伤害 | 调整后期望伤害 |
|-------|:-----------:|:-----------:|
| 暴击流（剑修） | 205% | 175% |
| 攻速流（剑修） | 140% | 165% |
| 差距 | -47% | -6% |

## 6. 构建型装备完善方案

### 6.1 保底机制（问题㉒）

**现状**：部分构建型装备仅3-5%掉率，期望获取时间2-30小时，且无任何保底。

**方案**：

```
保底规则（全局）：
  每击杀对应稀有怪/Boss N次，第N+1次必定掉落构建型装备

  N值设定：
    筑基期构建型装备：每20次
    金丹期构建型装备：每25次
    元婴期构建型装备：每30次
    化神期构建型装备：每35次

渐进掉率规则（配合保底）：
  每击杀对应怪物5次，掉率+2%（可叠加，触发保底后重置）
  基础掉率5% → 10次后7% → 20次后13% → 若仍未掉落→下次必掉

显示优化：
  怪物图鉴中显示"已击杀X次，当前掉率Y%，保底倒计时Z次"
```

### 6.2 锻造途径补充

```
新增：构建型装备锻造配方

获取方式：
  - Boss首杀：必定掉落对应构建型装备的锻造配方
  - 宗门兑换：金丹期后可用宗门贡献兑换（限3种）
  - 隐藏任务：约30%的构建型装备有隐藏锻造配方

锻造要求：
  - 锻造等级：筑基期装备Lv5+，金丹期Lv10+，元婴期Lv15+，化神期Lv18+
  - 材料：对应装备的"核心材料"×1（通过分解同名装备或Boss掉落获得）
  - 锻造成功率：60%（受锻造等级、炼器秘术加成）
  - 锻造时间：4-12小时（可灵石加速）
```

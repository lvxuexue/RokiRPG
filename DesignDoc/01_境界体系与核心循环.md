# 01 — 境界体系与核心循环

> **游戏名称（暂定）**：仙途·装备录  
> **类型**：单机修仙 / 装备驱动 / Roguelite探索

## 核心循环验证

```
玩家单次游玩体验（30-60分钟的循环）：

1. 登录 → 领取离线收益 → 查看日常任务（2分钟）
2. 进入适合等级的地图 → 探索+战斗（15-20分钟）
3. 查看掉落装备 → 替换/分解/强化（5分钟）
4. 材料收集 → 炼丹/锻造（5分钟）
5. 挑战副本/Boss（5-10分钟）
6. 主线任务推进（5-10分钟）
7. 整理背包 → 出售/存储 → 下线或继续

每次游玩确保有：
  - 短期目标（日常/升级/装备提升）
  - 不确定惊喜（随机掉落/奇遇/隐藏）
  - 持续养成反馈（属性增长/装备强化/功法参悟）
  - 可退出节点（每5-10分钟一个自然停顿点）
```

## 分阶段消耗引导（v1.1新增）

为避免金丹期经济压力集中（装备强化+功法参悟+技能升级+法宝炼制四重消耗同时出现），采用五阶段消耗引导：

```
炼气期(Lv1-20) — 引导：技能升级
  降费：技能升级金币-30%，灵石消耗-50%（仅限炼气期Lv1-5技能）
  目标：让玩家充分体验技能多样性和组合

筑基期(Lv21-40) — 引导：装备强化
  降费：装备强化+1~+5费用-20%，分解装备返还灵石+30%
  引导任务："装备之道"（强化+5后奖励灵石2000）
  目标：过渡到装备驱动阶段

金丹期(Lv41-60) — 引导：功法参悟
  降费：金色及以下功法参悟灵石消耗-25%
  周常任务：参悟成功3次→奖励悟道石×3+灵石5000
  目标：功法系统成为金丹期核心追求

元婴期(Lv61-80) — 引导：法宝炼制
  降费：法宝炼制材料需求-15%，本命法宝升级所需精华-20%
  目标：本命法宝成为元婴期核心养成线

化神期(Lv81-100) — 引导：终局Build收敛
  降费：暗金/红色功法参悟消耗降低，10阶装备强化成功率+5%
  目标：最终Build的完美收尾
```

## 防止内容枯竭的设计

1. 装备词条随机组合 → 同一件装备有数万种可能
2. 功法参悟/技能变异 → 同一技能有不同build方向
3. NG+新内容 → 通关后不是结束而是新开始
4. 灵兽/法宝养成 → 独立于主角的养成线
5. 爬塔/生存模式 → 无限挑战内容
6. 日常/周常任务 → 持续的目标感
7. 限时活动（可更新） → 持续的内容供给
8. 挑战成就 → 高难度目标的追求

# 04 战斗系统 — 全流程数值模拟与问题评估

> 评估方法：代入 Lv1/20/40/60/80/100 的实际属性值，逐帧模拟 ATB 节奏、伤害循环、Boss 战时长，验证所有公式在全等级范围内的合理性。

---

## 一、ATB 行动条：200倍速度跨度导致节奏崩溃

### 1.1 全等级行动间隔模拟

```
行动间隔 = 1000 / (SPD × 1.0 / 100) = 100000 / SPD   （无SPD加成时）

  等级   SPD(基础)   SPD(含装备)   行动间隔     每分钟行动次数
  ─────  ────────   ──────────   ──────────   ────────────
  Lv1     45          ~55         18.2 秒         3.3 次
  Lv5     57          ~80         12.5 秒         4.8 次
  Lv10    72         ~110          9.1 秒         6.6 次
  Lv20   105         ~180          5.6 秒        10.7 次
  Lv40   450         ~800          1.25秒        48.0 次
  Lv60  1500        ~2800          0.36秒       167 次
  Lv80  4200        ~7500          0.13秒       462 次
  Lv100 9000       ~16000          0.06秒      1000 次
```

**Lv1 战斗体验**：18秒才行动一次，石魔 HP~200，每击~50伤害，需4击=72秒/只。前30分钟玩家大部分时间在看行动条爬行。

**Lv100 战斗体验**：每秒16次行动，已经超出人类操作极限。自动战斗成为唯一选择——玩家被系统排除在外。

**结论**：ATB 线性公式 `fillSpeed = SPD/100` 在 SPD 跨度 200 倍的情况下彻底崩溃。

## 二、伤害公式：DEF 非线性导致"破甲强制"

### 2.1 全等级 DEF 减伤率模拟

```
DEF减伤 = DEF / (DEF + 1000)

  等级   玩家DEF   减伤率    怪物DEF    减伤率    玩家需要穿透?
  ─────  ───────  ────────  ────────  ────────  ──────────
  Lv1      12       1.2%      15        1.5%     —
  Lv20     80       7.4%      80        7.4%     —
  Lv40    500      33.3%     500       33.3%     —
  Lv60   1500      60.0%    2000       66.7%    需要
  Lv80   4000      80.0%    6000       85.7%    需要大量
  Lv100 10000      90.9%   15000       93.8%    强制堆叠
```

**Lv100 玩家攻击 Boss 的伤害路径**：

```
ATK=30000, 技能倍率2.5, Boss DEF=15000

无穿透：30000×2.5×(1-15000/16000) = 4688  → 对 250 万 HP Boss = 533 次攻击
50%穿透：30000×2.5×(1-7500/8500) = 9000    → 278 次攻击
75%穿透：30000×2.5×(1-3750/4750) = 15750   → 159 次攻击

→ 穿透从 50%→75%，伤害翻 1.75 倍
→ 防御穿透是整个游戏中效率最高的伤害属性
→ 所有非穿透 Build 在终局被数学碾压
```

### 2.2 物理 vs 法术的不对等

```
MR减伤 = MR / (MR + 800)   ← 除数 800 < DEF 的 1000

同等数值下：MR减伤 > DEF减伤
  DEF=10000 → 90.9%减伤
  MR =10000 → 92.6%减伤

→ 法术伤害天然比物理伤害低（同等数值下）
→ 且穿透对两者效率相同
→ 物理/法术的"对称设计"在数学上不对等
```

## 四、%HP 效果与 Boss 血量的矛盾

### 4.1 %HP DOT 对 Boss 的超模伤害

```
灼烧：每秒 3% HP，持续 6s = 18% HP

  对黑风妖王(HP=15000)：   15000×18% = 2700 → Boss 6秒掉血2700，约占18%
  对天道意志(HP=2,500,000)：2.5M×18% = 450,000 → 6秒掉45万，约占18%

→ 灼烧对 Boss 的伤害效率与普通怪完全相同（都是 %HP）
→ 但对 Boss 的绝对伤害量是普通怪的 166 倍
→ 但施放灼烧的成本完全相同（都是1个技能+等量MP）

暗+任意·侵蚀：8%当前HP，CD 15s
  Boss开场满血 → 2.5M×8% = 200,000 伤害（1个元素反应 = 2000次普攻）
  Boss HP 50% → 1.25M×8% = 100,000 伤害
```

**结论**：%HP 效果在 Boss 战中是压倒性的最优策略。任何依赖固定数值的技能/Build 都无法与 %HP 竞争。这导致元素反应（尤其是暗+任意）成为必选项，而非可选项。

## 五、构建型装备与战斗系统的兼容性问题

### 5.1 冰脉护符 vs Boss 免疫

```
冰脉护符效果：冰系技能不再减速 → 改为叠冰晶，5层冻结+爆发

Boss 规则（§4.2-4.3）：
  眩晕/冰冻/沉默 → 免疫，改为减速替代
  控制时间永久减半

冲突：
  冰脉护符移除了冰系的减速效果
  但 Boss 免疫冻结 → 冰晶5层的爆发触发"冻结"被替换为"减速"
  → 但冰脉护符已经把减速移除了
  → 结果：5层冰晶 = 什么都不会发生
  → 这件构建型装备对 Boss 完全无效
```

### 5.2 燃烧之心延迟引爆被 ATB 节奏打乱

```
燃烧之心：火伤不即时扣血，3秒后引爆 160%

Lv40(ATB间隔0.9s)：3秒内有约 3 次行动 → 可以在引爆前叠更多火伤
Lv100(ATB间隔0.06s)：3秒内有约 50 次行动 → 引爆时炎爆值早已溢出无数次

→ 延迟3秒在高 ATB 速度下失去了"节奏控制"的设计意图
→ 变成了"每3秒自动炸一次"的被动效果
```

### 5.3 暗影斗篷的闪避触发在高命中环境下失效

```
暗影斗篷：闪避成功 → 暗影形态 2s (下技能+40%)

实际闪避率 = min(40%, DODGE% + 闪避Buff%) - (HIT% - 95%)

Lv100 怪物 HIT% 估算：~120%（随等级增长）
  → 实际闪避率 = 40% - (120%-95%) = 15%
  → 只有 15% 概率触发暗影形态
  → 每 6-7 次被攻击才触发一次
  → 在 0.06s 间隔下，触发窗口存在但不可感知
```

### 5.4 自动战斗 AI 完全忽略构建型装备

```
当前 AI（均衡模式）：
  if HP<40% → 吃药
  if HP<25% → 回血技能
  if buff可用 → buff
  if 可触发反应 → 反应技能
  CD好的最高伤技能 → 释放
  否则 → 普攻

AI 不知道的构建型效果：
  ❌ 雷电之握：不知道需要 3技能→1普攻 的循环
  ❌ 燃烧之心：不知道应该叠炎爆值再引爆
  ❌ 分裂者护腕：不知道应该靠近怪群触发弹射
  ❌ 回响之戒：不知道高CD技能的回响价值更高
  ❌ 无尽回廊：不知道走位可以布残影阵
  ❌ 混沌之握：不知道如何使用随机获得的终极技

→ 12 件构建型装备中，至少 6 件在自动战斗下完全失效
→ 而 Lv60+ 的 ATB 速度已经迫使玩家使用自动战斗
→ 构建型装备和自动战斗在终局互相排斥
```

## 六、战斗评价的不可达问题

### 6.1 S 评价条件逐项检验

```
S 评价条件：无伤 + 60秒内 + 连击30层 + 元素反应3次

以 Boss 战检验每项的可达成性：

  黑风妖王(Lv15)：无伤→难但可练 / 60秒→5.7分钟不可能 / 连击30→需68次命中=在60秒内不可能
  幽冥殿主(Lv40)：无伤→3阶段Boss极难 / 60秒→2.6分钟不可能
  天道意志(Lv100)：无伤→5阶段Boss几乎不可能 / 60秒→30秒内不可能

→ S 评价在所有 Boss 战中不可达成
→ A 评价(120秒)在前期 Boss 战也不可达
→ 战斗评价系统形同虚设——它评价的不是"你打得怎么样"，而是"你的数值够不够碾压"
```

## 八、改进策略

### 8.1 P0-1：ATB 公式从线性改为对数

```
当前：fillSpeed = SPD / 100

改为：
  fillSpeed_base = 40 × log10(SPD / 10 + 1) / 100
  fillSpeed = fillSpeed_base × (1 + SPD加成%)

效果验证：

  等级   SPD    旧间隔    新间隔    每分钟行动
  ─────  ─────  ────────  ────────  ──────────
  Lv1     55    18.2s      8.9s       6.7次
  Lv20   180     5.6s      5.5s      10.9次
  Lv40   800     1.25s     3.9s      15.4次
  Lv60  2800     0.36s     3.4s      17.6次
  Lv80  7500     0.13s     3.1s      19.4次
  Lv100 16000    0.06s     2.9s      20.7次

→ 行动间隔稳定在 3-9 秒范围（全等级）
→ 前期从 18 秒加速到 8.9 秒（仍然偏慢但可接受）
→ 终局稳定在约 3 秒/次（战术选择有意义）
→ SPD 成长依然有价值（20/8.9=2.25倍加速），但不失控
```

### 8.2 P0-2：DEF 公式增加递减常数

```
当前：减伤 = DEF / (DEF + 1000)

改为：
  减伤 = DEF / (DEF + 1000 + DEF² / 15000)

效果验证：

  DEF     旧减伤    新减伤    说明
  ─────  ────────  ────────  ──────────
    100     9.1%      9.0%    前期不变
    500    33.3%     28.9%    微调
   1000    50.0%     40.9%    开始递减
   5000    83.3%     64.1%    显著递减
  10000    90.9%     72.4%    终局穿透不再是强制
  15000    93.8%     75.8%    极限值

同时将 DEF 和 MR 统一用同一个除数基准：
  MR减伤 = MR / (MR + 1000 + MR² / 15000)  ← 与 DEF 对称
```

### 8.3 P0-3：%HP 效果对 Boss 衰减

```
%HP 伤害对 Boss 衰减公式：
  Boss实际%HP伤害 = 技能%HP值 × (1 - Boss境界系数×0.15)

  境界系数：炼气1.0/筑基1.3/金丹1.6/元婴2.0/化神2.5

  灼烧(3%HP/s)对天道意志(系数2.5)：
    实际 = 3% × (1 - 2.5×0.15) = 3% × 0.625 = 1.875% HP/s
    总量 = 1.875%×6s = 11.25% HP（从18%降至11.25%）

  暗+侵蚀(8%当前HP)对天道意志：
    实际 = 8% × 0.625 = 5% 当前HP

→ %HP 在终局仍然有价值，但不再是压倒性的唯一最优
→ 固定数值伤害 Build 有了竞争空间
```

### 8.4 P1-5：冰脉护符 Boss 兼容修正

```
修改冰脉护符的叠层爆发逻辑：

  对普通/精英/稀有怪：5层→冻结2.5s+破碎伤害（不变）
  对 Boss：5层→"冰晶破碎"（无冻结）
    → 造成层数×ATK×2.5的绝对伤害（无视 Boss 冻结免疫）
    → Boss 减速40%持续3s（替代冻结的控场效果）
    → 冰晶层数清零

→ Boss 战中冰脉护符仍有完整价值，只是控场替换为伤害+减速
```

### 8.5 P1-6：自动战斗 AI 构建型装备感知

在 AI 决策中新增"构建型装备检测"分支：

```
function autoBattleAI():
    -- 新增：构建型装备感知
    equippedUniques = getEquippedUniqueEffects()
    
    -- 雷电之握感知
    if hasUnique("combo_attack") and comboCounter == 2:
        优先释放 CD 最短的技能（凑满第3层）

        停止释放火系技能（炎爆值已够，等引爆）

    -- 暗影斗篷感知
    if hasUnique("dodge_trigger") and hasBuff("shadow_form"):
        优先使用最高伤害技能（利用+40%窗口）
    
    -- 其余按原有逻辑
    ...
```

### 8.6 P1-7：战斗评价改为相对条件

```
当前：无伤+60秒内+连击30层+反应3次 → S

改为（基于玩家等级与Boss等级的对比）：

  等级差 = 玩家等级 - Boss等级

  S：等级差≤-5 + 无伤             （越级挑战+无伤=真正的S）
  A：等级差≤0  + HP>50%           （平级挑战）
  B：等级差≤5  + 通过              （正常通关）
  C：通过                          （任何方式通关）
  D：取消（不再惩罚使用复活）

→ 评价反映的是"你挑战了多难的敌人"，而非"你的数值是否碾压"
→ 越级无伤=S 是真正的技术验证
```

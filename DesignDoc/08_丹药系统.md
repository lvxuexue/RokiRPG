| 丹药类别 | 用途 | 使用限制 | 战斗中可用 |

| 特殊丹 | 各种特殊效果 | 视具体丹药 | 视具体 |

## 3. 丹药品质体系

同一丹方可产出不同品质的丹药：

| 丹药品质 | 效果倍率 | 产出概率(基础) | 附加条件 |
|----------|----------|---------------|----------|
| 劣质 | 0.6x | 10% | 炼丹等级低时 |
| 普通 | 1.0x | 60% | 标准 |
| 优良 | 1.3x | 20% | — |
| 极品 | 1.7x | 8% | 炼丹暴击 |
| 完美 | 2.5x | 2% | 极低概率 |

品质提升因素：
- 炼丹等级每级+0.5%极品率
- 使用高品质丹炉+5~15%优良以上率
- 武火炼制+10%极品率（但-15%成功率）
- 「炼丹宗师」秘术+20%优良以上率

### 4.2 炼丹完整流程

```
1. 选择丹方（已学会的丹方列表）
2. 选择丹炉（多个丹炉可并行炼制）
3. 投入材料（自动从背包扣除）
4. 选择火候：
   ├── 文火：成功率+15%，炼制时间×1.5，品质无加成
   ├── 中火：标准
   └── 武火：成功率-15%，炼制时间×0.7，极品率+10%
5. 选择辅材（可选）：
   ├── 催化剂：成功率+10%（消耗灵石粉末）
   └── 稳定剂：失败时50%概率保留主材料（消耗妖兽骨粉）
6. 开始炼制（等待时间或灵石加速，也可看广告立即完成——日限3次，与锻造/参悟共用额度，详见10_商店系统.md §2.2④）
7. 结果判定：
   ├── 大成功(暴击)：产出×2-5，品质提升1-2级
   ├── 成功：产出×1，品质按概率
   ├── 部分成功：产出×1但劣质品质
   ├── 失败：材料损失，获得「药渣」(可回收30%材料)
   └── 大失败(5%)：炸炉！材料全损+丹炉耐久-5
```

## 6. 丹药毒性/抗药性系统

### 6.1 抗药性

```
同类丹药连续使用产生抗药性：
  第1次：100%效果
  第2次(同日)：90%效果
  第3次(同日)：75%效果
  第4次(同日)：55%效果
  第5次+(同日)：30%效果

抗药性每日重置。
使用「清毒丹」可立即重置抗药性。
```

### 6.2 丹毒

```
使用属性丹/修炼丹会累积「丹毒」：
  - 丹毒值 0-80：无影响
  - 丹毒值 81-150：修炼速度-5%
  - 丹毒值 151-250：全属性-3%
  - 丹毒值 251+：HP/MP-8%

丹毒自然衰减：每天-15点（修炼状态下-20点/天）
使用「清毒丹」清除：-30点/颗（清毒丹自身不增丹毒）
使用「化毒丹」清除：-60点/颗（化毒丹自身不增丹毒）
属性丹丹毒值下调50%（原5→2-3点/颗）

【v1.1调整】丹毒自然衰减从-10提升至-15点/天，修炼丹丹毒全面下调。
          正常服用5颗修炼丹（如大聚灵丹×5=15点丹毒）与自然衰减持平，
          只有额外服用属性丹才会累积丹毒，日常修炼丹使用无压力。

设计意图：正常服用的属性丹+修炼丹约累积80-120点丹毒，
         维持在无影响或轻微影响的范围内。
         不加控制连续大量服用才会触及惩罚阈值。
```

### 6.3 突破丹防SL设计（新增）

```
突破丹成功率=100%，不存在失败。

作为平衡，材料需求上调：
  - 筑基丹:筑基草5→8,内丹1→2,灵石10→30
  - 结金丹:金丹草5→8,内丹1→2,灵石5→10
  - 破境丹:破境草5→8,内丹1→2
  - 化神引:化神草5→8,内丹1→2

100%成功+材料上调的设计消除了SL刷结果的动机，
同时保持了材料收集的挑战性。
```

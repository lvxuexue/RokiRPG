## 2. ATB行动条机制（完善）

### 2.1 行动条核心规则

```
1. 所有单位根据SPD属性填充行动条
2. 行动条上限1000，达到上限获得行动权
3. 填充速度 = 40 × log10(SPD / 10 + 1) / 100 × (1 + SPD加成%) + 固定加速  单位：条/秒
   例：SPD=200，加成20% → 填充速度=40×log10(21)/100×1.2≈0.63条/秒 → 满条约1.6秒
   全等级行动间隔稳定在 3-9 秒（SPD成长约2.25倍加速，但不会失控）
4. 多人同时满条时，SPD高者优先行动
5. SPD完全相同时，玩家优先
6. 行动后行动条归零
7. 战斗中SPD变化实时影响填充速度
```

### 2.2 行动消耗表

| 行动类型 | 消耗 | CD触发 | 备注 |
|----------|------|--------|------|
| 普通攻击 | 1行动权 | 无 | 基础伤害，无消耗 |
| 主动技能 | 1行动权 + MP | 触发技能CD | 不同技能CD独立 |
| 终极技能 | 1行动权 + 全部MP | 每场限1次 | 化神期可2次 |
| 使用道具 | 1行动权 | 不触发技能CD | 道具自身有CD(60s) |
| 防御 | 1行动权 | 无 | 50%减伤至下次行动 |
| 逃跑 | 1行动权 | 失败则浪费 | 成功率见下方公式 |
| 切换灵兽 | 1行动权 | 60s CD | 切换出战斗灵兽 |

### 2.3 逃跑公式

```
逃跑成功率 = min(90%, (我方平均SPD / 敌方平均SPD) × 50% + 20%)
Boss战逃跑成功率减半
世界Boss不可逃跑
连续逃跑每次成功率-15%（最低5%）
```

## 3. 伤害计算公式（完整版）

### 3.1 物理伤害

```
步骤1 — 基础伤害：
  baseDmg = ATK × 技能倍率

步骤2 — 增伤汇总（加法叠加）：
  incDmg = 1 + ATK增伤% + 物理增伤% + 全伤增伤% + 对应属性增伤%

步骤3 — 防御减免（二次递减）：
  defReduce = 1 - (目标DEF / (目标DEF + 1000 + 目标DEF² / 15000))
  注：防御穿透直接减去目标DEF：有效DEF = DEF × (1 - 穿透%)
  减伤曲线：DEF=100→9.0% | DEF=1000→40.9% | DEF=5000→64.1% | DEF=15000→75.8%
  → 终局防御不再趋近100%，穿透是优势选项而非强制

步骤4 — 暴击判定：
  有效暴击率 = 攻击方CRIT% + 技能暴击加成 - 目标暴击抵抗%
  边际递减：有效暴击率超过70%后，超出部分×0.7（硬上限80%不变）
    示例：面板暴击率85% → 有效暴击率 = 70% + (85%-70%)×0.7 = 70%+10.5% = 80.5% → Cap at 80%
  暴击率 = min(80%, 有效暴击率)
  if random(0,100) < 暴击率:
      critMult = CRIT_DMG (基础150%, 上限350%)（v1.1从400%下调）
  else:
      critMult = 1.0

步骤5 — 属性克制：
  elementMult = 1.5(克制) / 1.0(无克制) / 0.7(被克制)

步骤6 — 目标减伤：
  dmgReduce = 1 - min(90%, 目标受伤减免% + 防御Buff%)

步骤7 — 随机波动：
  variance = random(0.95, 1.05)

最终物理伤害 = baseDmg × incDmg × defReduce × critMult × elementMult × dmgReduce × variance
```

### 3.2 法术伤害

```
与物理伤害公式相同，但：
  - 基础伤害用AP替换ATK
  - 防御减免用MR替换DEF（除数基准与DEF统一）
  - 法术穿透替代物理穿透

defReduce_magic = 1 - (目标MR / (目标MR + 1000 + 目标MR² / 15000))
```

### 3.3 持续伤害（DOT）

```
DOT伤害 = 基础DOT值 × (1 + DOT增伤%) × 属性克制 × (1 - 目标减伤%)
DOT不受防御/抗性减免
DOT默认不触发暴击（装备「毒素精通」被动后可暴击，暴击率=角色暴击率×0.5）
DOT不触发闪避
DOT伤害频率：每1秒/跳

%HP类DOT对Boss衰减：
  Boss实际%HP伤害 = 技能%HP值 × (1 - Boss境界系数 × 0.15)
  境界系数：炼气1.0 / 筑基1.3 / 金丹1.6 / 元婴2.0 / 化神2.5
  例：灼烧(3%HP/s)对天道意志(系数2.5) → 3%×(1-2.5×0.15)=1.875%HP/s
  → %HP在终局仍有用但非碾压级优势
```

### 3.4 闪避与命中

```
命中判定：
  实际命中率 = min(98%, 攻击方HIT% + 技能命中修正)
  实际闪避率 = min(40%, 目标DODGE% + 闪避Buff%)
  
  if random(0,100) < (实际闪避率 - (实际命中率 - 95%)):
      伤害=0 (Miss)，不触发任何命中效果
```

### 8.1 自动战斗策略选择

### 8.2 AI决策逻辑

```
自动战斗AI（均衡模式伪代码）：

function autoBattleAI():
    equippedUniques = getEquippedUniqueEffects()  -- 检测构建型装备
    
    if HP < 40% and hasHealingPotion and potionCD == 0:
        usePotion()
        return
    
    if HP < 25% and hasHealSkill and healSkillCD == 0:
        useSkill(healSkill)
        return
    
    -- 构建型装备感知：生死逆转珠
    if hasUnique("death_prevent") and HP < 15% and not hasBuff("soul_state"):
        可以故意不治疗，等待灵魂状态触发（留给玩家手动决策）
    
    -- 构建型装备感知：暗影斗篷
    if hasUnique("dodge_trigger") and hasBuff("shadow_form"):
        优先使用最高伤害技能（利用+40%增伤窗口）
        useSkill(getHighestDamageSkill())
        return
    
    -- 构建型装备感知：雷电之握
    if hasUnique("combo_attack") and getComboCounter() == 2:
        优先使用最低CD技能（凑满第3层触发雷击）
        useSkill(getLowestCDSkill())
        return
    
    -- 构建型装备感知：燃烧之心
    if hasUnique("damage_delayed_burst") and getTargetBurnValue() > ATK * 5:
        停止火系技能（炎爆值已够），改用其他元素技能
        useSkill(getNonFireSkill())
        return
    
    -- 构建型装备感知：分裂者护腕
    if hasUnique("projectile_chain") and getNearbyEnemyCount() >= 2:
        优先使用单体投射技能（触发弹射）
        useSkill(getSingleTargetProjectileSkill())
        return
    
    -- 构建型装备感知：回响之戒
    if hasUnique("skill_echo"):
        优先使用CD最长的可用技能（回响复制的价值最高）
        useSkill(getLongestCDAvailableSkill())
        return
    
    -- 构建型装备感知：元素共鸣器
    if hasUnique("elemental_resonance"):
        优先使用目标身上元素种类最少的技能（扩展元素种类触发共鸣）
    
    if hasBuffSkill and buffSkillCD == 0 and not hasActiveBuff:
        useSkill(buffSkill)
        return
    
    -- 检查元素反应机会
    if canTriggerReaction():
        useSkill(bestReactionSkill)
        return
    
    -- 优先用CD好的高伤技能
    for skill in sortByDamage(availableSkills):
        if skill.cd == 0 and enoughMP(skill):
            useSkill(skill)
            return
    
    -- 都没有就普攻
    normalAttack()

## 10. 技能修改器系统（SkillModifierManager）

构建定义型装备（详见 `03_装备系统.md` §11）通过此系统在战斗中生效。核心逻辑：在技能施放/伤害结算等关键节点，检查装备槽中是否存在 `uniqueEffect`，若存在则按 `modifyType` 修改对应行为。

### 10.1 执行流程

```
技能施放请求 → SkillModifierManager:onSkillCast(skillData)
  ├── 遍历所有装备槽
  ├── 检查 equipment.uniqueEffect 是否存在
  ├── 匹配 targetSkill（nil=不限技能）
  └── 调用对应的 modifyType handler
       ├── 修改技能参数（伤害/投射物数/CD等）
       ├── 注入额外行为（弹射/回响/延迟等）
       └── 触发视觉特效
```

### 10.2 修改类型规格

| modifyType | 触发时机 | 行为 | 使用装备 |
|------------|---------|------|---------|
| `projectile_chain` | 投射物命中后 | 检测半径8m内最近敌人→生成新投射物飞向目标 | 分裂者护腕 |
| `skill_echo` | 技能施放后 | 技能ID+参数入队列→1.2s定时器→自动执行(50%伤害) | 回响之戒 |
| `damage_to_shield` | 受到伤害后 | 伤害值×30%→生成吸收盾(5s,不叠加取最大) | 坚韧之心 |
| `damage_delayed_burst` | 火伤结算时 | 不扣血→累加至目标炎爆值→3s定时器→引爆(160%)+5m溅射 | 燃烧之心 |
| `debuff_replace` | 施加debuff前 | 拦截原效果→替换为自定义叠层逻辑→满层时触发爆发 | 冰脉护符 |
| `combo_attack` | 技能施放后 | 计数器+1→满3时替换普攻为强化攻击→计数器清零 | 雷电之握 |
| `dodge_trigger` | 闪避判定成功 | 施加shadow_form buff(2s): 下技能+40%, 不可锁定 | 暗影斗篷 |
| `elemental_resonance` | 施加元素debuff后 | 遍历目标所有元素debuff→每种触发一次对应属性伤害 | 元素共鸣器 |
| `death_prevent` | HP降至0时 | 拦截死亡→HP=1+灵魂状态(4s无敌,+100%伤害,禁回复)→结束恢复35%HP | 生死逆转珠 |
| `movement_trail` | 角色移动时(每0.3s) | 生成trail marker(3s寿命,碰撞检测)→触发伤害+减速 | 无尽回廊 |
| `random_ultimate_grant` | 定时器(每45s) | 从9系终极池随机抽取→添加临时技能槽→45s未用则替换 | 混沌之握 |
| `boss_skill_steal` | Boss死亡时 | 从该Boss技能池随机1个→存储至本命法宝列表(上限3)→额外技能槽 | 轮回之证 |

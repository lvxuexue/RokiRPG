# 07 功法系统 — 丰富度评估与全流程模拟

## 一、丰富度多维度评估

### 1.1 评分总览

| 维度 | 评分 | 说明 |
|------|:----:|------|
| 功法总量 | ★★★★☆ | 约60部功法覆盖5境界×4类型，品类较全 |
| 类型分化 | ★★★★★ | 主修/战斗/身法/秘术4条线完全独立，定位清晰 |
| 品质与层数 | ★★★★★ | 7品质×3-9层，参悟深度感强 |
| 参悟系统 | ★★★★☆ | 成功率+心得保底+隐藏效果池，有一定深度 |
| 境界衔接 | ★★★★☆ | 每境界约8-12部新功法可选，过渡自然 |
| 获取多样性 | ★★★★☆ | 掉落/宗门/奇遇/商店/Boss/隐藏6种途径 |
| 组合策略 | ★★★☆☆ | 共鸣系统有5个条件但过于简单，缺乏深度交互 |
| 秘术功法 | ★★☆☆☆ | 仅列出10部秘术，5类生活技能各仅1-2部可选 |
| 悟道石经济 | ★★☆☆☆ | 消耗表完整但获取途径未量化 |
| 数据模型 | ★★★★★ | 完整可落地 |

**综合评分：3.6/5 — 框架扎实，60部功法量够用，参悟系统有深度。主要问题是秘术类薄弱、悟道石经济模糊、共鸣深度不足**

### 1.2 功法实际统计

```
按境界×类型统计：

炼气期（8部修炼 + 5部战斗 + 2部身法 + 3部秘术）= 18部
筑基期（4部修炼 + 4部战斗 + 2部身法 + 2部秘术）= 12部
金丹期（4部修炼 + 4部战斗 + 2部身法 + 2部秘术）= 12部
元婴期（3部修炼 + 2部战斗 + 1部身法 + 1部秘术）= 7部
化神期（2部修炼 + 2部战斗 + 1部身法 + 1部秘术）= 6部
                                    ──────────
                                    总计：约55部

境界分布特点：前期多后期少（炼气18→化神6），
              这与"越高级越稀有"的设计理念一致。

类型不平衡：
  修炼功法：21部（38%）——最多
  战斗功法：17部（31%）
  身法功法：8部（15%）——偏少
  秘术功法：9部（16%）——偏少且每类仅1-2部可选
```

## 二、全流程模拟

### 2.1 炼气期（Lv1-20）功法体验

```
Lv1 — 初始功法：
  槽位：仅1主修+1战斗+1身法（3/5槽，秘术未解锁）
  初始赠送：吐纳术(白,修炼) + 基础剑法(白,战斗)
  身法：空槽（需任务获取疾风步）

  ⚠️ 初始无身法=SPD无加成，ATB填充慢
  ⚠️ 吐纳术仅+10%修炼速度，效果微弱到几乎不可感知

Lv3-5 — 首次功法获取：
  任务获得：长春功(绿,修炼) + 疾风步(绿,身法)
  修炼速度从+10%→+15%（+5%差异，仍不可感知）
  ⚠️ 这个阶段的功法效果都是用百分比计算的，前期基数小效果不明显

Lv5-10 — 首次选择压力：
  可选功法增多：烈火诀(蓝),寒玉功(蓝),青木经(蓝),金刚掌(绿),灵蛇剑诀(蓝)
  但槽位有限：1主修+1战斗+1身法=3部

  Build决策：
    火灵根 → 烈火诀(主修)+火麟刀法(战斗,需掉落)+疾风步(身法)
    冰灵根 → 寒玉功(主修)+待定(战斗)+疾风步(身法)
    ⚠️ 冰灵根此时没有冰系战斗功法（寒冰心法要筑基才出）

Lv15-20 — 参悟初体验：
  吐纳术(白)满层3层→参悟2次即可满（消耗悟道石×2+灵石×700）
  长春功(绿)满层5层→参悟4次（消耗悟道石×5+灵石×3700）
  ⚠️ 悟道石获取未量化——如果靠掉落/任务供给不足，参悟就停了

  参悟到满层时：
    吐纳术满层+20%修炼速度
    长春功满层+25%修炼速度+HP成长+20%
    ⚠️ 白→绿满层的差别只有5%修炼速度+HP成长——体感差异极小

炼气期总结：
  功法效果微弱（前期基数小，百分比加成感知弱）
  选择有限（每槽位1-2个选项）
  参悟体验平淡（满层%差异小）
  评分：★★☆☆☆
```

### 2.2 筑基期（Lv21-40）功法体验

```
Lv21 — 关键解锁：
  第2战斗槽位解锁！→ 可同时装备2部战斗功法
  ⚠️ 但秘术槽仍未解锁（文档未说明秘术解锁条件）
     假设秘术在筑基期解锁（灵草辨识等需要采药Lv3+）
  
  功法配置变为：1主修+2战斗+1身法(+1秘术?)=4-5部

  战斗功法选择（火灵根为例）：
    槽1：火麟刀法(蓝,Lv6满层=ATK+20%,火伤+18%)
    槽2：天罡剑诀(蓝,宗门)或 万毒经(紫,Boss掉落)
    ⚠️ 2部战斗功法的效果是加法叠加还是独立判定？文档未说明

Lv25-35 — 紫色功法替换：
  紫霞神功(紫,隐藏任务)替换长春功(绿)
  修炼速度+35%+HP/MP成长+15% ← 感知明显了
  参悟至满层：+50%修炼速度+HP/MP+25%

  ⚠️ 隐藏任务触发条件不明确，可能错过
  ⚠️ 没有"功法替换提示"——玩家可能不知道紫霞神功比长春功好多少

Lv35-40 — 参悟压力增加：
  蓝色功法满层6层需要参悟5次（悟道石×9+灵石×8700）
  紫色功法满层7层需要参悟6次（悟道石×12+灵石×18700）
  ⚠️ 如果没有稳定的悟道石收入，此时只能维持1-2部功法满层

筑基期总结：
  第2战斗槽解锁是重大提升
  紫色功法开始感知明显（35-50%加成）
  参悟资源开始吃紧
  评分：★★★☆☆
```

### 2.3 金丹期（Lv41-60）功法体验

```
Lv41 — 秘术槽假设已解锁：
  5槽全齐：1主修+2战斗+1身法+1秘术
  金/暗金功法开始大量出现

  修炼选择（火灵根）：
    五行轮转功(金,奇遇) 修炼+50%+五行伤害+25%
    vs 太乙真诀(紫,宗门) 修炼+40%+全属性+12%
    → 五行轮转完胜，但需要奇遇

  战斗选择：
    九天剑典(紫)+天魔解体大法(金,Boss)
    天魔解体：伤害+30%但每秒自损1%HP
    ⚠️ 负面效果功法的"风险/收益"需要数值验证
        每秒1%HP=100秒死亡，但战斗中还有回复手段

Lv50-60 — 暗金/红色入门：
  元婴期功法预览（大衍诀、诛仙剑阵等）

  参悟至7-8层需要：
    悟道石20-40个 + 灵石50000-100000
    ⚠️ 单部金功法的8层参悟需要大量资源
        如果悟道石缺乏→卡在4-5层无法提升

金丹期总结：
  5槽全齐，Build成型
  金/暗金功法效果显著（40-60%+额外特效）
  参悟资源成为核心瓶颈
  功法共鸣开始触发（同属性/同品质奖励）
  评分：★★★★☆
```

### 2.4 元婴期-化神期（Lv61-100）功法体验

```
Lv61-80 — 元婴期：
  修炼：大衍诀(金,+60%) 或 焚天诀(金,+55%火伤40%)
  战斗：诛仙剑阵(金,额外剑阵攻击)+万法归宗(暗金,全技能+30%CD-20%)
  身法：缩地成寸(金,先手必触发)

  ⚠️ 元婴期功法仅列出7部（3修炼+2战斗+1身法+1秘术）
     每槽位仅1-2个选项→选择空间缩小
     →"越高级越稀有但选择也更少"这可能让终局体验变单调

Lv81-100 — 化神期终局：
  修炼：混沌真经(暗金,+80%) 或 天道法则(红,+100%+每级额外5属性点)
  战斗：开天剑法(暗金) + 六道轮回功(红,每场复活1次)
  身法：踏破虚空(暗金,免疫一切控制)
  秘术：创世之书(红,全生活技能满级+必出最高品质)

  ⚠️ 化神期仅6部功法——这是全游戏最高境界但选择最少！
     红色功法虽然强但获取条件苛刻（天道意志/隐藏结局）

参悟至9层（红色8→9层）：
  基础成功率10%×品质系数0.4=4%
  期望次数：25次=悟道石×200+灵石×1,250,000
  ⚠️ 红色功法9层满参悟理论上需要海量资源
     → 终局红色功法更可能是"4-5层就够用"，9层是收藏家目标

功法传承（NG+）：
  刻录传承玉简→功法层数清零
  ⚠️ 刻录消耗"大量灵石"未量化
     "大量"是多少？如果太低→NG+太简单；太高→传承形同虚设
```

## 三、发现的问题

### 🔴 致命问题

#### 1. 悟道石经济完全未定义

```
功法参悟系统的核心资源是「悟道石」
但整个文档中没有提到悟道石的任何获取途径/频率/数量！

当前参悟消耗：
  1部蓝色功法满层(6层)需悟道石×9
  1部紫色功法满层(7层)需悟道石×12
  1部金色功法满层(8层)需悟道石×28
  1部红色功法满层(9层)需悟道石×200(期望)

5部功法全满层所需悟道石：约60-300个

如果悟道石1小时掉2-3个→金色满层需约10小时（合理）
如果悟道石1小时掉0.5个→金色满层需约56小时（不合理）

→ 悟道石掉率直接决定了功法系统"能不能玩"
→ 这是当前功法系统的最大黑洞
```

#### 2. 功法效果前期不可感知

```
炼气期功法加成：
  吐纳术(白)：修炼速度+10%
  长春功(绿)：修炼速度+15%

修炼速度的基数是什么？如果是基础经验获取率：
  假设基础100exp/击杀
  吐纳术→110exp，每只多10exp
  击杀100只多1000exp——前期需要约2000exp升1级
  → 多1000exp还不够半级

  → 白色功法"+10%"在前期几乎不可感知
  → 建议前期功法给"固定值+百分比"混合，如"修炼速度+10%, 每击杀额外+5exp"
```

#### 3. 秘术功法严重发育不良

```
现有9部秘术：
  灵草辨识、矿脉感知、炼丹初解 — 炼气
  炼器入门、灵药培育 — 筑基
  炼器大师、丹道真解 — 金丹
  炼丹宗师 — 元婴
  创世之书 — 化神

问题：
  - 挖矿/锻造/采药/炼丹各1-2部可选 → 无Build差异
  - 探索/神识/交易完全没有秘术覆盖
  - 每境界1-2部秘术 → 大部分时间秘术槽是"固定最佳选择"
  - 秘术"满层"的差异仅5-10% → 不值得投入悟道石
```

### 🟡 严重问题

#### 4. 境界越高选择越少

```
每境界功法数量：炼气18→筑基12→金丹12→元婴7→化神6
                    ^^^^                    ^^^  ^^^
                    最多                     锐减 最少

化神期每槽位仅1-2个功法可选
→ 终局Build本质上没有选择
→ 所有化神玩家用同一套功法配置
```

#### 5. 功法替换无过渡设计

```
从长春功(绿,Lv5满层)升级到烈火诀(蓝)：
  长春功已投入悟道石×5+灵石×3700参悟至满层
  更换后这些投入全部作废

→ 与装备系统的"传承石"问题一模一样
→ 功法系统也需要"功法心得传承"（部分参悟进度转移）

当前文档提到了传承玉简（元婴解锁，NG+用）但不是用于替换场景的
```

#### 6. 参悟时间门槛

```
参悟8→9层需要等待16小时（可用灵石加速80%→3.2小时）
→ 即使加速，满层一部红功法需等待时间累计约64小时

这个设计在单机游戏中意义不大：
  - 纯时间等待=强制挂机/修改系统时间
  - 不如改为"消耗额外灵石立即完成"
```

### 🟢 次要问题

#### 7. 共鸣条件过于简单

```
5个共鸣条件中：
  主修+副战同属性 → 几乎必定触发（同元素Build自然满足）
  全5部同品质 → 终局自然追求
  → 共鸣不是"Build策略"而是"必然奖励"
  → 缺少牺牲/权衡型共鸣（如"牺牲修炼速度换战斗加成"）
```

#### 8. 功法名称与效果经常脱节

```
例：万毒经(战斗功法) → 攻击附带中毒+每层毒增伤5%
    但命名为"经"暗示它是修炼功法，会误导玩家

例：太上忘情道 → +70%修炼速度但禁用回复技
    这个负面效果很极端，但获取是"隐藏奇遇"
    → 如果玩家不看攻略随机获得，可能毁掉Build
```

## 四、改进建议

| 优先级 | 问题 | 建议 |
|--------|------|------|
| P0 | 悟道石经济 | 定义悟道石获取：Boss掉落(1-3个)、日常任务(1个)、分解满层功法返还50%、灵石商店(3000/个) |
| P0 | 前期效果不可感知 | 白色/绿色功法改为基础值+百分比混合；如吐纳术"修炼+10%,每击杀额外+3exp" |
| P0 | 秘术发育不良 | 扩展至5类生活技能各3-4部可选，新增探索/神识/交易类秘术各2-3部 |
| P1 | 高级境界选择少 | 元婴期功法从7部扩至12部，化神期从6部扩至10部 |
| P1 | 功法替换无补偿 | 新增"功法参悟转移"：消耗灵石将旧功法50%参悟进度转移至新功法 |
| P1 | 参悟时间门槛 | 改为"灵石加速无上限"（可立即完成），取消强制等待 |
| P2 | 共鸣深度 | 新增3-5个牺牲/权衡型共鸣条件 |
| P2 | 传承玉简消耗量化 | 明确刻录消耗：灵石×50000+悟道石×10（元婴期） |

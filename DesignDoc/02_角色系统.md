## 1. 角色属性架构

### 1.1 属性总览

```
角色属性
├── 基础属性（等级成长 + 装备加成 + 功法加成 + 丹药加成）
│   ├── 生命值（HP）        — 角色存活能力
│   ├── 灵力值（MP）        — 施放技能消耗
│   ├── 攻击力（ATK）       — 基础物理伤害基数
│   ├── 防御力（DEF）       — 物理减伤
│   ├── 法术强度（AP）      — 法术伤害基数
│   ├── 法术抗性（MR）      — 法术减伤
│   ├── 速度（SPD）         — ATB行动条填充速度
│   ├── 暴击率（CRIT%）     — 暴击概率（硬上限80%）
│   ├── 暴击伤害（CRIT DMG）— 暴击倍率（基础150%，上限400%）
│   ├── 命中率（HIT%）      — 基础95%，对抗闪避
│   └── 闪避率（DODGE%）    — 闪避概率（硬上限40%）
│
├── 修炼属性（功法/丹药/奇遇成长）
│   ├── 灵根资质 — 修炼速度倍率（0.5~2.0x）
│   ├── 悟性    — 功法参悟成功率、技能熟练度增益
│   ├── 神识    — 探索探测距离、隐藏发现率、先手判定
│   ├── 根骨    — HP成长系数、防御额外加成
│   ├── 气运    — 掉落率、奇遇触发率、暴击闪避幸运修正
│   └── 魅力    — NPC商店折扣、特定剧情选项解锁
│
└── 抗性属性（五行+特殊）
    ├── 金抗 / 木抗 / 水抗 / 火抗 / 土抗
    ├── 雷抗 / 冰抗 / 毒抗 / 暗抗
    └── 抗性上限75%，超出部分转为对应属性伤害加成（转化率20%）
```

### 1.2 属性计算公式

```
最终HP  = (基础HP + 装备HP) × (1 + 气血加成%) × (1 + 根骨/200)
最终MP  = (基础MP + 装备MP) × (1 + 灵力加成%)
最终ATK = (基础ATK + 装备ATK) × (1 + ATK加成%) 
最终DEF = (基础DEF + 装备DEF) × (1 + DEF加成%) × (1 + 根骨/300)
最终AP  = (基础AP + 装备AP) × (1 + AP加成%)
最终MR  = (基础MR + 装备MR) × (1 + MR加成%)
最终SPD = (基础SPD + 装备SPD) × (1 + SPD加成%)

暴击率   = 基础暴击 + 装备暴击 + 技能暴击（硬上限80%）
暴击伤害 = 150% × (1 + 爆伤加成%)（上限350%）（v1.1从400%下调）
闪避率   = 基础闪避 + 装备闪避 + 技能闪避（硬上限40%）

伤害减免 = DEF / (DEF + 1000 + DEF²/15000)  — 物理（二次递减，终局趋近75%而非100%）
法术减免 = MR  / (MR  + 1000 + MR²/15000)  — 法术（除数与物理统一为1000）

DEF/MR各关键值的减伤率：
  DEF=100   → 9.0%     DEF=1000  → 40.9%    DEF=5000  → 64.1%
  DEF=10000 → 72.4%    DEF=15000 → 75.8%    DEF→∞    → 趋近~87%（实际极限）
```

## 3. 角色创建与灵根系统

### 3.1 灵根类型

| 灵根类型 | 概率 | 修炼速度 | 主属性数 | 特性 |
|----------|------|----------|----------|------|
| 天灵根（单属性） | 10% | 2.0x | 1 | 该属性技能效果+50%，受克属性伤害+25% |
| 双灵根 | 15% | 1.5x | 2 | 双系亲和，可同时触发双属性被动 |
| 三灵根 | 30% | 1.2x | 3 | 三系基础亲和，无明显短板 |
| 四灵根 | 30% | 1.0x | 4 | 标准修炼速度 |
| 五灵根（杂灵根） | 12% | 0.8x | 5 | 全属性抗性+15%（被动「五行亲和」）；化神期觉醒"五行归元"→修炼速度翻倍至1.6x，五行伤害+30% |
| 异灵根·雷 | 1% | 1.8x | — | 雷伤+40%，SPD+15% |
| 异灵根·冰 | 1% | 1.6x | — | 冰伤+35%，控制时间+30% |
| 异灵根·暗 | 1% | 1.3x | — | 暗伤+50%，受光属性伤害+30%；被动「暗夜之子」夜间全属性+10%，暗属性抗性+15% |

### 3.2 灵根主属性

```
五行：金、木、水、火、土
特殊：雷、冰、暗（异灵根专属）

五行相生（战斗外修炼加成）：
  金生水 → 水属性功法参悟速度+20%
  水生木 → 木属性功法参悟速度+20%
  木生火 → 火属性功法参悟速度+20%
  火生土 → 土属性功法参悟速度+20%
  土生金 → 金属性功法参悟速度+20%

五行相克（战斗伤害修正）：
  金克木 → 金打木 ×1.5，木打金 ×0.7
  木克土 → 木打土 ×1.5，土打木 ×0.7
  土克水 → 土打水 ×1.5，水打土 ×0.7
  水克火 → 水打火 ×1.5，火打水 ×0.7
  火克金 → 火打金 ×1.5，金打火 ×0.7
```

### 3.3 角色创建流程

```
1. 外观自定义：性别、发型、脸型、道袍初始样式（6-8选项/项）
2. 灵根觉醒：随机生成灵根（可免费刷新5次，后续消耗灵石）
3. 命名：输入法号/道号
4. 初始属性检定（固定+小幅随机波动±5%）
5. 选择初始技能倾向：剑修/法修/体修/医修/暗修
   ├── 剑修：初始获得「基础剑法」+ ATK+10%
   ├── 法修：初始获得「灵气操控」+ AP+10%
   ├── 体修：初始获得「炼体术」+ DEF+10%、HP+10%
   ├── 医修：初始获得「回春术」+ 治疗效果+20%
   └── 暗修：初始获得「暗影步」+ 暴击率+5%
6. 确认创建，进入序章

创建完成后自动获得：
  - 全套1阶凡品装备（青竹剑/布巾/麻布衣/草鞋，详见03_装备系统.md §1.1）
  - 15初始技能点（可学1-2个新技能或升级已有技能）
  - 1000灵石 + 500金币 + 5颗小回灵丹
  - 初始主动槽位=4（Lv1即可构建完整技能循环）
```

## 4. 境界突破系统

### 4.1 突破条件与消耗

| 突破目标 | 等级要求 | 必备丹药 | 材料消耗 | 突破成功率（基础） |
|----------|----------|----------|----------|-------------------|
| 炼气→筑基 | Lv20 | 筑基丹×1 | 灵石×100 | 60% |
| 筑基→金丹 | Lv40 | 结金丹×1 | 上品灵石×50、妖兽内丹(灵)×3 | 45% |
| 金丹→元婴 | Lv60 | 破境丹×1 | 灵晶×20、元婴级内丹×1 | 30% |
| 元婴→化神 | Lv80 | 化神引×1 | 仙灵石×10、化神级内丹×1 | 20% |

突破成功率受以下因素影响：
- 丹药提供固定加成（筑基丹+30%→90%，结金丹+30%→75%...）
- 可使用额外丹药/灵石继续提升（每颗额外+5%，上限95%）
- 灵根修炼速度越高，基础成功率+5%~15%

### 4.2 渡劫机制

```
突破时触发渡劫小游戏：

炼气→筑基（三九小天劫）：
  - 3波落雷，每波3道
  - 操作：左右闪避，每波10秒
  - 每被击中1次，突破后HP上限-5%
  - 全部闪避：获得"完美筑基"称号，HP+20%

筑基→金丹（六九中天劫）：
  - 6波落雷，每波3道 + 心魔幻象
  - 心魔：出现镜像敌人，需在15秒内击败
  - 完美渡劫：获得"金丹大成"，暴击伤害+30%

金丹→元婴（九重大天劫）：
  - 9波混合天劫（落雷+天火+心魔）
  - 每3波出现一次天道质问（选项判定，悟性影响正确率）
  - 完美渡劫：元婴品质+1阶

元婴→化神（九九归一劫）：
  - 终极天劫，9波连续不断
  - 包含所有类型攻击+因果律攻击
  - 渡劫失败：等级回退至Lv75，需重新准备
  - 完美渡劫：获得"化神至尊"称号，全属性+25%
```

### 4.3 突破失败处理

```
突破失败：
  - 丹药和材料全部消耗（不返还）
  - 等级不下降
  - 获得"劫灰"×1（累积2个可兑换"渡劫心得"：下次渡劫落雷速度-15%；累积3个可兑换渡劫保护符）
  - 冷却时间后方可再次突破（按境界：24h→12h炼气/18h筑基/20h金丹/24h元婴）
  - 再次突破时成功率+10%（可叠加，最多+30%）

渡劫试炼模式（新增）：
  - NPC：宗门"渡劫长老"
  - 功能：不消耗材料，模拟当前境界的渡劫小游戏
  - 限制：每日3次免费，超出消耗灵石×500/次
  - 无奖励，纯练习用途
```

## 6. 称号与声望系统

### 6.1 称号获取

| 称号来源 | 示例 | 加成 |
|----------|------|------|
| 境界称号 | 「筑基修士」「金丹真人」「元婴老祖」「化神道君」 | 对应境界属性+5%~15% |
| 成就称号 | 「百晓生」「炼丹大师」「屠龙者」 | 特定属性加成 |
| Boss首杀 | 「黑风克星」「幽冥终结者」 | 对该Boss伤害+15% |
| 渡劫称号 | 「完美筑基」「金丹大成」 | 永久属性加成 |
| 活动称号 | 限时称号 | 限时强力Buff |

同时只能装备1个境界称号 + 1个成就称号，属性叠加。

### 6.2 声望系统

```
声望阵营：
  ├── 宗门声望（加入的宗门）→ 影响宗门商店/功法兑换
  ├── 坊市声望 → 影响商人折扣/特殊商品解锁
  ├── 正魔声望（正道↔魔道）→ 影响剧情分支/NPC态度
  └── 散修声望 → 影响奇遇/隐藏任务触发

声望等级：冷漠→中立→友善→尊敬→崇敬→传说
```

# 11 掉落规则 — 丰富度评估与全流程整合模拟

> 评估基准：参考 TapTap 2024-2025 热门修仙暗黑Like ARPG 的市场标准（修仙奇谭、飞升秘境、封妖奇谈、修与真、小妖問道 等），以及暗黑Like装备系统的经典设计原则。

### 1.3 致命缺陷：所有装备都只是"数值叠加"

这是本游戏掉落系统与 TapTap 成功产品之间**最根本的差距**。

#### 市场标准：构建定义型装备 (Build-Defining Uniques)

TapTap 头部产品的共同特征是拥有**改变玩法**的装备：

```
飞升秘境 的「混沌百变暗金」：
  "装备后，你的火焰技能改为释放混沌火球，随机附加3种元素异常"
  → 不是"火伤+20%"，而是"火技能的行为变了"

修与真 的「吞噬系统」：
  "吞噬一件同阶装备，永久获得其一条随机词条"
  → 不是"ATK+100"，而是"你的成长方式变了"

暗黑破坏神（经典参照）的「巫师之刺」：
  "你的电击技能有25%概率释放一道连锁闪电"
  → 不是"电伤+25%"，而是"每次电击都是一个抽奖"
```

#### 本游戏的现状

```
本游戏任何装备的效果：
  武器「烈焰之剑」→ ATK+500, 火伤+15%, CRIT+8%, 攻速+12%
  武器「寒冰之剑」→ ATK+500, 冰伤+15%, CRIT+8%, 攻速+12%
  
  → 两把剑的"玩法"完全相同，只是伤害数字的颜色不同
  → 玩家更换装备时，战斗方式没有任何变化
  → 装备选择退化为"哪个数字大用哪个"
```

**这是本报告最重要的结论：**

> 当前设计将"随机词条"等同于"丰富性"，但实际上 8类主词条 × 14类次词条 = 112 种组合中的每一种，对玩家来说体验完全相同——都是数值变化。真正的丰富性来自**行为变化**（技能形态改变、触发新机制、改变资源循环），而非数值变化。

#### TapTap 玩家社区的共鸣

在 TapTap 社区中，关于暗黑Like装备搜集游戏疲劳期的讨论指出：
- 玩家在毕业后的核心倦怠来源是"满屏掉落全是垃圾"——即使掉的是金色装备
- 解决方案方向：**凝练系统**——将词条从掉落中剥离为可主动打造的"凝练材料"，让玩家从"赌掉落"变为"主动构建"
- NightBloodW 的 **CPS系统**——怪物可将自身特质词条附加到玩家装备上，让每次战斗都有"被怪物改变"的风险与机遇

### 1.4 各机制逐项评估

#### 掉落判定流程 — 合格但缺惊喜层级

```
当前流程：
  1. 必定掉落金币
  2. 材料掉落判定
  3. 装备掉落判定
  4. 特殊掉落判定

问题：缺少"意外惊喜"层。
对比 Bob Nystrom (Dropping Loot) 的设计原则：
  "每次击杀怪物，都应该有极小的概率掉落真正令人惊叹的东西。
   '这一只可能就是大奖'的期待感，是游戏中最核心的情感之一。"

建议新增第5层判定：
  5. 奇迹掉落判定（独立概率 0.01%-0.1%）
     → 跨阶位装备、限定外观、隐藏技能书、奇遇触发器
```

#### 保底机制（怜悯系统）— 阈值过高

```
当前：击杀Boss未获得紫+装备累计幸运值，满100时下次Boss必掉金+

问题：
  - 按每30分钟1次Boss战计算，触发一次需要 50小时
  - 在正常游玩节奏下，玩家可能通关都触发不了1次
  - TapTap 同类产品（如飞升秘境）的保底通常设在 20-30次

建议：幸运值满 25 时触发（约12小时），每次触发后重置
```

#### Boss首杀奖励 — 设计优秀，本游戏的亮点

```
每个Boss首次击杀：
  ✅ 品质+1（最低紫色）—— 保证了首杀的"高光时刻"
  ✅ 突破材料×1 —— 与进度系统挂钩
  ✅ 传承石×1 —— 为后续装备换代提供保障

这是当前掉落系统中设计最精良的部分，建议保持并作为核心体验锚点。
```

#### 连杀奖励 — 效果感知弱

```
连续击杀同类型怪物50只→掉落率+20%

问题：
  - 50只门槛在前期偏高（炼气期怪物分布稀疏，不容易连续找到50只同类型）
  - 掉率10%→12%，差异2个百分点，玩家完全感知不到
  - 缺少视觉/音效反馈（没有"连杀计数"的UI提示）

建议：
  - 改为阶梯式：25只(+15%) → 50只(+30%) → 100只(稀有怪出现率翻倍)
  - 增加屏幕连杀计数器+特效反馈
```

#### 传承石体系 — 设计意图好但数量不足

```
全游戏约15-20个Boss
首杀提供约 15-20 个传承石
玩家需求：10槽位 × 5次换代 = 50个（缺口约30个）

当前补充途径：
  - Boss常规30% → 需刷约100次Boss
  - 稀有怪10% → 约300次稀有怪击杀
  - 灵石商店5000/个(周限3) → 约10周才能凑齐

建议：Boss常规掉率提升至 50%，稀有怪提升至 20%
     新增：分解紫+品质装备时 10% 概率返还传承石
```

### 1.5 综合评分（10维度，以 TapTap 市场标准为参照）

| 维度 | 评分 | 参照基准 | 说明 |
|------|:----:|---------|------|
| 掉落频率 | ★★★☆☆ | 市场标准：5-8击杀/件 | 12.5击杀/件白装，低于市场均值 |
| 品质梯度 | ★★★★☆ | 市场标准：6级 | 7级(含暗金)比市场多一层，优势 |
| Boss首杀 | ★★★★★ | 多数产品无此机制 | **独家优势**，设计精良 |
| 保底机制 | ★★★☆☆ | 市场标准：20-30次触发 | 100次阈值过高，约50h才触发 |
| 惊喜掉落 | ★★☆☆☆ | 市场标准：独立"奇迹"判定 | 缺少跨阶掉落、限定外观等 |
| 构建定义型装备 | ★☆☆☆☆ | 飞升秘境/修与真 均有 | **最大的缺失**——所有装备仅数值叠加 |
| 定向获取 | ★★☆☆☆ | 市场标准：秘境限定掉落池 | 完全缺失，纯随机 |
| 掉落-玩法联动 | ★★☆☆☆ | NightBloodW CPS怪物烙印 | 掉落与战斗策略零关联 |
| 终局驱动力 | ★★☆☆☆ | 市场标准：赛季/万能暗金 | 传说0.2%+无定向=纯肝 |
| 掉落多样性 | ★★★☆☆ | 4类 vs 市场6-8类 | 缺奇遇/外观/钥匙/灵兽蛋 |

**掉落综合评分：2.6/5（与之前评估一致）**

**一句话总结**：框架完整（甚至Boss首杀和传承石设计优于市场），但缺少"灵魂"——没有让玩家说出"我要去刷这件装备"的目标物。

## 二、全流程整合模拟

以下将装备、技能、功法、丹药、掉落五系统作为一个整体，追踪"中等运气"玩家的完整体验。

### 2.1 Lv1-5（前30分钟）— 三重空窗期

```
进入游戏时的状态：
  ├── 装备：0件（4空槽）
  ├── 技能：0个（0技能点 → 无法学任何技能）
  ├── 功法：吐纳术(白,+10%修炼)+基础剑法(白)（效果不可感知）
  ├── 丹药：0颗
  ├── 战斗：只有普攻
  └── 掉落：击杀~5只石魔 → 金币50-200 + 材料×2-3 + 可能1件白装

对比 TapTap「这剑仙只炼剑」：开局送全套入门装备+3个基础剑法
对比 TapTap「躺平修仙传」：开局送自动战斗+初始功法

问题叠加（三重空窗）：
  1. 装备空窗：4个槽位全空，DEF=0，HP≈200，普攻伤害~15-20
  2. 技能空窗：0技能点=无法学任何技能=只有普攻一个动作
  3. 功法空窗：+10%修炼加成在基数极小时（100exp/只→110exp）完全无法感知

  → 石魔 HP 180-400，需要普攻 12-20 次（约30-40秒/只）
  → 在手游场景中，前5分钟只有普攻 = 极高流失风险
```

### 2.2 Lv5-15（约1.5小时）— 系统逐步解锁但节奏拖沓

```
Lv5：获得5技能点 → 学火球术(白)+金刃术(白)
  战斗变为：火球→金刃→普攻×N→循环
  技能倍率150-180%，与普攻(100%)差距仅1.5-1.8倍
  → "有技能"和"没技能"的实际体验差异远小于玩家预期

Lv5-10：掉落累积
  ├── 装备：2-3件白+1件绿（4槽中约填满3个）
  ├── 材料：青石矿×5-8+凡铁×3-5
  ├── 金币：约500-1000
  └── 灵石：极少（需卖材料换），学技能需要灵石但灵石不够

Lv10：项链槽解锁（第5槽）
  → 槽位增加但背包里可能没有项链可装备
  → "解锁空槽"体验 = 没有正向反馈，反而是提醒"你还缺一件"

Lv10-15：首次遇到精英怪
  ├── 掉落：良品(绿)+可能上品(蓝)
  ├── 材料：开始获得2阶材料（玄铁矿）
  └── 但玩家还在用1阶装备，2阶材料暂时无用 → "无用品掉落"
```

### 2.3 Lv15-20（约1小时）— 首次Boss战

```
Lv15 Boss战「黑风妖王」：
  我方状态：
    ATK~160, HP~1200, DEF~60
    装备：4-5件白/绿混搭，可能1件蓝
    技能：2-3个白/绿技能（2-3级）
    功法：吐纳术(白,满层)+基础剑法(白,3层)+疾风步(绿,刚学)
    丹药：可能2-3颗小回灵丹 (回复200HP=~17%HP)

  Boss: HP 15000, ATK 180
  战斗时间：2-3分钟
  首杀掉落：保底紫装×1 + 突破材料×1 + 传承石×1

  ★ 游戏中第一个真正的"记忆点"
  紫装带来约25%的ATK提升，感知明显

  但存在两个遗憾：
  1. 唯一保底紫装若掉在非武器槽（如鞋子）→ 兴奋感大幅打折
  2. 紫装仍是"数值更高"，没有改变战斗方式
     → 对比「飞升秘境」首件传奇可能附带"击杀爆炸"效果
     → 本游戏首件紫装只是"打怪快了一点"
```

### 2.4 Lv20-21（境界突破）— "一切归零"感

```
突破到筑基期：
  获得：属性点+20、技能点+5、解锁戒指1+腰带（+2槽）
  战力瞬间跃升：HP+40-50%, ATK+15-20%

  但紧接而来的"重置"效应：
  ├── 装备：2阶→3阶全面换代
  │   2阶紫+5武器 (ATK~135) vs 3阶绿+0武器 (ATK~200)
  │   → 之前投入的强化灵石、传承石全废
  │   → 全游戏仅15-20次首杀传承石，10槽需要50个
  ├── 功法：筑基期功法需从0开始参悟
  │   → 长春功(绿)投入的悟道石×5+灵石×3700 变沉没成本
  ├── 丹药：小回灵丹(200HP) vs 回灵丹(800HP)
  │   → 旧丹药库存沦为垃圾
  └── 技能：新技能需要更多技能点，旧低阶技能继续占槽位

  矛盾体验：
  突破本应是"我变强了！"的正向高峰
  但伴随的是"所有投入归零，一切要从头再来"的焦虑
```

### 2.5 Lv21-40（筑基期，约4-5小时）— 全流程最佳阶段

```
这是整个游戏体验最完整的阶段：
  ├── 装备：7槽位，3-4阶装备循环
  │   锻造/强化/套装开始有意义
  │   强化+8以下成功率可控，灵石消耗可承受
  ├── 技能：4主动+2被动，战斗循环开始有策略感
  ├── 功法：4槽位（主修+2战斗+身法），紫色功法效果可感知(35-50%)
  ├── 丹药：属性丹开始使用（+500HP≈15-25%）
  └── Boss战：幽冥殿主3阶段 = 设计最精良的Boss

  ★ 筑基期是游戏的"黄金期"
  系统丰富度刚好，经济未到崩溃点
```

### 2.6 Lv41-60（金丹期，约5-6小时）— 系统膨胀，经济开始断裂

```
金丹期新增：
  + 第5主动槽 + 第1终极槽（首次体验终极技！约20-25h才解锁）
  + 法宝系统（独立养成线）
  + 第2戒指槽（9槽位）

  经济压力急剧上升：
  ├── 强化：+7→+10单件需灵石8-15万
  │   灵石年收入：500-1000/小时 → 单件+10需80-150小时
  │   → 从+10开始，强化经济与灵石获取速率脱节
  ├── 功法：金色功法满层需悟道石×28+灵石×50000+
  │   悟道石获取途径完全未定义 → 功法系统瘫痪
  ├── 丹药：结金丹成功率~78%
  │   与筑基丹成功率完全相同 → 炼丹师零成长感
  └── 法宝：第一次炼制消耗5000-10000灵石

  设计意图 vs 实际可达：
  设计："全身金色+强化+12+满层功法+2个满级法宝"
  实际："紫装混搭+强化+7+3层功法+1个入门法宝"
  → 差距大到让玩家觉得"天花板上不去"
```

### 2.7 Lv61-80（元婴期，约5-6小时）— 内容密度骤降

```
新解锁：本命法宝（10槽满）、附魔系统

但实际新增内容量急剧下降：
  功法：仅7部可选（每槽位1-2个选择）—— 比炼气期的18部下降61%
  丹方：仅7个（炼气期有9个）
  套装：仅2套（7阶+8阶各1套）
  技能：6主动槽需6个同元素技能，金/木系勉强够，暗系仅3个

内容密度曲线：
  炼气期(Lv1-20)： 18功法+9丹方+大量技能解锁 → 内容丰富
  元婴期(Lv61-80)： 7功法+7丹方+几乎无新技能 → 内容密度下降60%
  
  但元婴期游玩时间(~5-6h)是炼气期(~3.5h)的1.5倍
  → 内容更少，时间更长 → "又臭又长"体验
```

### 2.8 Lv81-100（化神期，约8-10小时）— 终局疲软

```
终局状态（中等运气实际可达）：
  ├── 装备：6-7件9阶暗金+1-2件传说+1-2件8阶暗金
  ├── 强化：+15~+18（+20需约220小时/件 → 不可达）
  ├── 套装：2-3件套效果（6件套 = 0.01%概率 → 不可达）
  ├── 技能：5-6个满级技能（技能点仅够9/15满级）
  ├── 功法：6部（全游戏最少），4-5层（满层需悟道石×200 → 不可达）
  ├── 丹药：圣灵丹回复~17%HP（Boss战中几乎无用）
  └── 终极技：2个（同元素只有1个可选 → 无选择空间）

终局驱动的三重缺失：
  1. 数值天花板不可达 —— +25强化需1500万灵石≈3000小时
  2. 内容天花板太低 —— 化神期内容量仅为炼气期的30%
  3. 没有"证明自己"的出口 —— 无排行榜、无赛季、无爬塔、无速杀榜

对比 TapTap「飞升秘境」的终局设计：
  - 赛季制：每赛季对抗不同外域文明，赛季贡献可兑换太古装备
  - 秘境地牢：无限爬塔+远古传奇专属掉落
  - 万能暗金：通过任务链获取可定制部位/套装/词条的装备

→ 本游戏终局：玩家卡在"能看到天花板但永远够不到"的挫败区间
→ 市场标杆终局：每次赛季重置带来新的追逐目标
```

## 三、境界内容密度曲线

```
各境界内容量对比（功法+丹方+套装+技能数的相对密度）：

炼气期 ████████████████████ 100%  (18+9+2+20+ ≈ 49)
筑基期 ██████████████████    90%  (12+10+2+15+ ≈ 39)
金丹期 ██████████████        70%  (12+8+2+10+ ≈ 32)
元婴期 ████████              40%  (7+7+2+5+ ≈ 21)
化神期 ██████                30%  (6+6+2+3+ ≈ 17)

炼气期内容量是化神期的3倍+
化神期游玩时间(~10h)是炼气期(~3.5h)的3倍
→ 内容密度与游玩时长完全反向
→ 越玩内容越少，终局体验单调

对比 TapTap 标杆产品的处理方式：
  - 「修与真」：越高级开放越多系统（混沌至宝吞噬、灵宝合成）
  - 「飞升秘境」：赛季制保证终局始终有新内容
  → 本游戏需要在高境界补充系统深度，而非简单递减
```

### 5.3 P0 — 境界突破重置：保留投入价值

### 5.5 P0 — 突破丹SL漏洞：消除赌博感

**当前问题**

```
四个突破丹成功率全部约78%：
  筑基丹：55%+8%(Lv5)+15%(文火)=78%
  结金丹：40%+15%(Lv10)+8%(炉)+15%(文火)=78%
  破境丹：30%+20%(Lv15)+12%(炉)+15%(文火)=77%
  化神引：20%+25%(Lv18)+15%(炉)+15%(文火)=75%

→ 炼丹师从Lv1到Lv80，四个突破丹的成功率几乎完全一样
→ 每次突破都像在赌博，且失败=材料全损+1h~1周farm
→ 玩家必定使用SL大法（单机游戏无法阻止）
```

**推荐方案：100%成功率 + 材料成本体现难度**

```
改为：
  筑基丹：成功率 100%，材料不变
  结金丹：成功率 100%，材料改为 金丹草×8（原5）+ 妖兽内丹(灵)×2（原1）
  破境丹：成功率 100%，材料改为 破境草×12（原?）+ 元婴内丹×2
  化神引：成功率 100%，材料改为 天道碎片×3（原1）+ 混沌石×3（原1）

设计意图：
  → 突破不再是"赌博"，而是"集齐材料的旅程"
  → 材料数量差异化体现难度（筑基草5个/2h vs 天道碎片3个/2周）
  → 但一旦集齐，100%成功——玩家可以"计划"突破时间
  → 失败惩罚转移到渡劫系统（渡劫失败=材料不返还+冷却24h）
  
  如果保留失败率（备选方案）：
    突破丹失败时 → 丹药保留（不消耗）+ 仅消耗辅料+灵石
    → 核心材料不损失，SL驱动力大幅降低
    → 但保留"再来一次"的紧张感
```

### 5.9 P2 — 将"数值装备"转化为"改变玩法的装备"

当前所有装备的差异只有数字。以下设计直接给出**可落地的装备数据模型扩展 + 具体装备列表**，每件装备明确：掉落来源、构建变化、实现方式。

#### 5.9.1 数据模型扩展

在现有 `EquipmentData` 基础上新增一个可选字段：

```lua
EquipmentData = {
    -- ... 现有字段 ...
    
    -- 新增：独特效果（仅金+品质可能拥有）
    uniqueEffect = nil,  -- nil = 普通装备, 否则 = UniqueEffectData
}

UniqueEffectData = {
    id = "unique_fire_001",        -- 效果ID
    name = "分裂之火",              -- 效果名（显示在装备tooltip）
    category = "skill_modify",     -- 类型: skill_modify / trigger / transform / aura
    description = "火球术分裂为3颗，每颗造成原伤害的60%",
    
    -- 具体效果参数（由战斗系统解析）
    targetSkill = "fireball",      -- 影响的技能ID
    modifyType = "projectile_split", -- 修改类型
    modifyParams = {               -- 修改参数
        splitCount = 3,
        damageRatio = 0.60,
    },
    
    -- 视觉反馈（必需——玩家需要看到变化）
    vfx = {
        projectilePrefab = "fireball_split",
        hitEffect = "fire_explosion_small",
        trailColor = {1.0, 0.3, 0.0},  -- 橙色尾迹（区别于原版红色）
    },
    
    -- 掉落限制
    minQuality = "gold",           -- 最低品质
    exclusiveSlot = "weapon",      -- 限定槽位（nil=不限）
    exclusiveTier = 3,             -- 最低阶位
}
```

**实现量**：战斗系统新增一个 `SkillModifierManager`，在技能释放前检查装备槽中是否有 `uniqueEffect` 并应用修改。核心逻辑约 200-300 行。

| 无尽回廊 | ✅ 残影轨迹+破碎特效 | ✅ 走位从"躲避"变为"主动布阵封锁" | ✅ 走位回到纯防御行为 |
| 混沌之握 | ✅ 手套混沌能量+元素色晕 | ✅ 每45秒被迫调整策略——"这把给了冰终极，怎么用？" | ✅ 回到固定Build |
| 轮回之证 | ✅ Boss虚影叠加 | ✅ Boss战=收集技能—每次Boss击杀都有新可能性 | ✅ 额外技能槽消失 |

**核心原则**：每一件构建型装备，卸下时玩家应该感到"玩法变无聊了"——而不是"数值变小了"。

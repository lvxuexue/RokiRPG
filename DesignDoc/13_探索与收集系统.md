## 1. 世界地图架构

```
世界地图层级：

第一层：修真大陆（开放世界，按境界解锁区域）
  ├── 新手区域：青牛村、翠屏山、灵石矿洞
  ├── 炼气区域：修真坊市、黑风山、灵兽森林
  ├── 筑基区域：五大宗门驻地、幽冥沼泽、冰晶洞窟
  ├── 金丹区域：上古战场、金丹秘境、虚空裂缝（入口）
  ├── 元婴区域：灵界都市、天魔战场、远古龙巢
  └── 化神区域：天道崖、混沌裂缝、飞升台

第二层：秘境副本（独立地图，消耗门票进入）
  ├── 日常秘境（每日免费1次，后续消耗门票）
  │   ├── 灵石秘境（大量灵石）
  │   ├── 材料秘境（指定阶位材料）
  │   ├── 经验秘境（大量经验）
  │   └── 装备秘境（指定阶位装备）
  │
  ├── 挑战秘境（通关评价+排行榜）
  │   ├── 塔式爬塔（100层，每层递增难度）
  │   ├── Boss Rush（连续挑战Boss）
  │   └── 生存模式（无限波次，记录存活波数）
  │
  └── 特殊秘境（限时/隐藏）
      ├── 奇遇秘境（随机触发，稀有奖励）
      ├── 活动秘境（限时活动专属）
      └── 传承秘境（一次性，功法/技能传承）

第三层：洞府系统（个人空间）
  ├── 修炼室（离线修炼收益）
  ├── 炼丹室（炼丹加成）
  ├── 炼器室（锻造加成）
  ├── 药田（种植灵草）
  └── 藏经阁（存储功法，参悟加成）
```

## 4. 图鉴系统

### 4.1 怪物图鉴

```
图鉴条目：
  - 怪物名称、立绘、描述
  - 属性信息（HP/ATK/DEF/技能）— 击败后解锁
  - 掉落列表 — 击败后解锁
  - 击败次数统计
  - 弱点提示 — 击败50次后解锁

图鉴收集奖励：
  - 收集10种：经验+10000
  - 收集30种：灵石+1000
  - 收集50种：称号"百晓生"+稀有道具
  - 收集100种（全图鉴）：传说功法"万象天书"
```

### 4.2 装备图鉴

```
图鉴条目：
  - 装备外观、名称、品质
  - 属性范围
  - 获取来源
  - 是否已收集标记

收集机制：
  - 首次获得该装备时自动记录
  - 装备外观可幻化（使用已收集装备的外观）

图鉴收集奖励：
  - 每收集10件：灵石奖励
  - 收集整套套装：特殊称号+属性加成
  - 收集率50%：稀有锻造材料包
  - 收集率100%：传说装备"万象圣衣"
```

# 12 — 剧情与任务系统

---

## 1. 世界观设定

```
世界观背景：
  天地初开，混沌分阴阳，演化五行，诞生天道法则。
  万物遵循天道运转，修行者通过吸纳天地灵气、参悟天道法则，
  逐步突破生命极限，最终目标是超脱轮回、飞升仙界。

  然而天道有缺，每隔万年出现一次"天道裂痕"，
  域外天魔趁虚而入。上古大能牺牲自身补全天道，
  留下了遍布大陆的遗迹、功法和传承。

  主角出身于偏远山村，机缘巧合下发现自己身具灵根，
  从此踏上修仙之路，在探索上古遗迹的过程中，
  逐渐揭开天道裂痕的真相...

世界观层级：
  凡间（新手村→修真界）→ 灵界（金丹后可进入）→ 
  仙界通道（化神期）→ 飞升（游戏通关）
```

## 2. 新手剧情设计（前2小时体验）

### 序章：山村少年（Lv1-5，约30分钟）

目标：引导玩家熟悉基础操作，建立情感连接，**确保装备驱动循环从第一分钟开始**

流程：
1. 开场动画：天地异象，主角觉醒灵根
2. 任务「初识灵气」：学习吐纳术，首次修炼。**老者赠送初始装备「青竹剑」「布巾」「麻布衣」「草鞋」**
3. 任务「山中试炼」：击败3只石魔（现在有武器后每只约5次普攻击杀）。**必定掉落：良品(绿)1阶头部「灵狐皮帽」**，学会装备对比和更换
4. 任务「采集灵草」：采集5株回灵草。**途中首次发现铁宝箱→获得灵石×50+下品强化石×3**，学会探索与环境互动
5. 任务「炼制初丹」：首次炼丹体验（必定成功）。**奖励：上品(蓝)1阶武器「精铁剑」**，引导玩家感受品质差异
6. 任务「初试锻造」：使用采集的材料(青石矿×5+凡铁×3)锻造一件1阶装备。**首次锻造必定出良品+**，学会锻造系统
7. 任务「村中危机」：击败妖兽·炎狼（残血版），救下村民。**首杀稀有怪掉落极品(紫)1阶衣服**，第一次"装备兴奋时刻"
8. 获得传承：村中老者临终传授「长春功」+ 赠送**下品强化石×5+灵石×200**，引导强化系统
9. 踏上旅途：离开山村前，村长赠送**良品1阶鞋子+项链槽位预告**（"到了坊市记得买条好项链"）

### 第一章：修真坊市（Lv5-15，约60分钟）

目标：展开修炼世界，建立装备驱动循环

流程：
1. 到达坊市：认识各NPC（装备商/丹师/宗门使者/锻造师）
2. 任务「装备初识」：装备商赠送**上品(蓝)项链「灵玉坠」**——解锁第5槽位预告
3. 任务「灵石矿洞」：小副本，学会装备强化。**BOSS掉落传承石×1**，学会强化传承机制
4. 任务「妖兽讨伐」：第一次Boss战「黑风妖王」。**首杀保底极品(紫)2阶武器**——第二个"兴奋时刻"
5. 任务「宗门选拔」：选择加入宗门（五行宗门五选一）。**奖励对应属性良品2阶衣服+宗门贡献×100**
6. 解锁功能：开启日常任务、宗门商店。**引导查看套装图鉴——展示2/3/4件效果**
7. 任务「筑基之路」：收集筑基丹材料。**过程中自然farm到Lv15+，积累灵石约2000-3000**

### 第二章：筑基试炼（Lv15-20，约30分钟）

目标：第一次境界突破，核心玩法完全展开

流程：
1. 任务「收集筑基丹」：采集筑基草×5、获取妖兽内丹×1
2. 指导炼丹：NPC指导炼制筑基丹
3. 突破渡劫：小型天劫小游戏（闪避落雷）
4. 突破成功：境界提升动画，属性大幅增长
5. 解锁：筑基期全部功能（法宝、套装、高级副本）
6. 主线推进：发现上古遗迹线索

## 3. 任务类型

| 任务类型 | 数量 | 刷新 | 奖励 |
|----------|------|------|------|
| 主线任务 | 每境界10-15个 | 不刷新 | 经验/装备/功法/解锁 |

| 周常任务 | 每周3个 | 每周刷新 | 大量灵石/稀有材料 |

| 成就任务 | 累积触发 | 不刷新 | 成就点数/称号/特殊奖励 |

|------|----------|-----------|------|
| **飞升结局** | 修复天道，正常通关 | 最终选择"修复天道" | 标准结局（默认路径，完成主线即可） |
| **破天结局** | 打破天道法则 | 最终选择"打破天道" | 开创全新修炼体系（隐藏结局） |
| **守护结局** | 放弃飞升 | 最终选择"留在凡间" | 留在凡间守护修真界（感动结局） |
| **混沌结局** | 融合天道与魔道 | 最终选择"融合" | 成为新的天道意志（暗黑结局） |

### 5.2 各结局的达成路径

**飞升结局（默认路径）**：
```
条件：完成全部主线任务即可
Lv100击败天道意志后 → 对话选项"修复天道" → 结局
→ 不需要额外的隐藏条件
→ 所有玩家均可达成
```

**破天结局（隐藏）**：
```
前置条件（全部满足）：
  1. 收集全部5个天道碎片
     来源：化神期Boss/精英掉落（天道化身、天道神卫等）
  2. 收集混沌石×10
     来源：混沌之主·无+混沌裂缝+Boss掉落
  3. Lv98击败隐藏Boss「旧天道·残响」
     触发：子时携带5个天道碎片到达天道祭坛
     获得「旧天道记忆」（剧情物品）

Lv100击败天道意志后：
  → 持有「旧天道记忆」时出现隐藏选项"打破天道"
  → 选择后触发破天结局
```

**守护结局（感动）**：
```
前置条件（全部满足）：
  1. 凡间声望达到"崇敬"（6级声望中的最高级）
     来源：完成所有凡间支线任务+多次救助NPC+坊市消费累计
  2. 完成所有支线任务（不要求奇遇任务）
  3. 至少救助过散修NPC 5次（第二章·奇遇任务中触发）

Lv100击败天道意志后：
  → 满足条件时出现选项"留在凡间"
  → 选择后触发守护结局
```

**混沌结局（暗黑）**：
```
前置条件（全部满足）：
  1. 正魔声望均≥50（即同时拥有正道和魔道声望）
     正道来源：宗门贡献、救助NPC、正道抉择
     魔道来源：隐藏任务、劫掠NPC、魔道抉择
  2. 击败隐藏Boss「阎罗」（元婴Lv75区域Boss）
     获得「阎罗令牌」
  3. 拥有构建型装备「混沌之握」
     来源：混沌碎片×5合成 or 上古魔帝10%掉落

Lv100击败天道意志后：
  → 持有「阎罗令牌」+「混沌之握」时出现隐藏选项"融合天道与魔道"
  → 选择后触发混沌结局
```

### 5.3 抉择时机设计

所有结局的最终抉择出现在同一个节点：Lv100击败天道意志后的对话中。

```
天道意志（濒死）：
  "你...赢了。但你可知道，天道若碎，域外天魔将倾巢而入。
   我囚禁上古大能，是为了维持这最后的屏障...
   
   现在，选择吧——"

  选项1：「我愿修复天道」（→ 飞升结局）【始终可用】
  选项2：「天道该被打破了」（→ 破天结局）【需旧天道记忆】
  选项3：「我选择留下」（→ 守护结局）【需凡间崇敬+全支线】
  选项4：「天道与魔道，本是一体」（→ 混沌结局）【需阎罗令牌+混沌之握】
```

> 评估角色：天灵根(2%概率)，主属性火，修炼速度2.0x，火属技能效果+50%，受水属伤害+25%
> 初始倾向：法修
> 评估范围：02_角色系统 / 03_装备系统 / 05_怪物与敌人系统 / 06_技能系统 / 07_功法系统 / 08_丹药系统 / 11_掉落规则 / 12_剧情与任务系统

### 1.2 筑基期 Lv21-40（~3.5h，2.0x加速）

#### 突破瞬间变化

```
突破筑基(Lv21):
```

### 1.3 金丹期 Lv41-60（~4h，2.0x加速）

#### 突破瞬间

```
突破金丹(Lv41):
  主动槽+1 → 6主动槽
  终极技升级 → 焚天灭地从60%→100%（完整版）
  +装备槽：戒指2+法宝 → 9装备槽
```

火修技能(Lv41)：6主动槽，火技=4个(+天火燎原Lv28)。4/6=67%覆盖率，2个空槽。

Lv50焚天灭地(完整版)：500%火伤+灼烧场地(每2s×150%火伤)×15s。天灵根+50%→750%。全流程最高爆发。

#### 首个法宝：聚灵珠

Lv41任务「金丹之路」在宗门宝库领取聚灵珠(白)：
- 技能：灵力爆发 AP×200% AOE CD 45s
- 火修AP~2000(Lv41) → 4000 AOE伤害
- 对比火球术(ATK~1500×180%×1.5=4050) → 聚灵珠单发伤害≈火球术
- 聚灵珠是"入门法宝"，火修应尽快炼制火属性法宝替代

#### 构建型装备获取窗口

| 装备 | 来源 | 掉率 | 火修适配度 |
|------|------|:---:|:---:|
| 燃烧之心 | 炎魔领主(稀有)/天劫使者首杀 | 8%/15% | ★★★★★ 火修核心 |
| 冰脉护符 | 冰魄女王(稀有) | 8% | ★☆☆☆☆ 冰系，非火修 |
| 雷电之握 | 天劫使者(雷劫阶段) | 8% | ★★☆☆☆ 雷系，泛用 |
| 暗影斗篷 | 影魔之主(稀有) | 8% | ★★★☆☆ 泛用闪避 |

金丹期4件构建型装备中，仅1件为火修专属。冰脉护符(冰系)和雷电之握(雷系)对火修无专属价值。

#### 金/暗金功法参悟压力

金丹期功法以金品质为主：太乙真诀(紫)/五行轮转功(金)/九天剑典(紫)/天魔解体大法(金)。
- 金功满层8层需悟道石×28→按获取3-6/h，需5-10h
- 金丹期约4h，参悟资源不足以满层1部金功法

### 1.4 元婴期 Lv61-80（~4h，2.0x加速）

#### 突破瞬间

```
突破元婴(Lv61):
  主动槽+1 → 7主动槽（满）
  被动槽+1 → 5被动槽（Lv60时触发）
  +装备槽：本命法宝 → 10装备槽（满）
  附魔系统解锁
```

火修技能(Lv61)：7主动槽，火技=6个(+陨石术Lv36+烈焰之径Lv44)。6/7=86%覆盖率，仅1空槽。

#### 火系装不下的第7槽

火系可用主动技=7个(火球术+烈焰风暴+火神附体+天火燎原+陨石术+烈焰之径+凤凰涅槃Lv54)。7主动槽刚好填满7火技——零选择空间。

> 纯火Build在元婴期变成"填空题"而非"选择题"。7槽=7火技→Build的唯一变量是"变异分支选A还是B"。

#### 本命法宝觉醒

Lv61「元婴觉醒」获得「本源之种」(白)：
- 被动：每60s→HP×10%吸收盾
- 滋养至蓝品质(Lv3，消耗元婴内丹×5+灵石7万)→解锁「元婴出窍」(5s伤害+30%, CD 180s)
- 天灵根火修伤害+30%×火技伤害+50%=1.95×倍率叠加

#### 第7被动槽的焦虑 (Lv90)

被动7槽(Lv90满)，火系被动=3个。需要4个非火被动填充。
- 可选：土灵坚韧(+HP%)+木灵共生(回复)+金灵附体(爆伤)+电磁场(反伤)
- 火修被动不是"火系Build选择"，而是"有什么用什么"

#### 元婴期终点

| 系统 | 预估数值 |
|------|------|
| 等级 | Lv80，HP~55000, ATK~16000, AP~14000, DEF~9000 |
| 装备 | 10件蓝/紫/金/暗金混搭(7-8阶)，7-8件+12~+15 |
| 技能 | 7主动(7火=100%)，5被动(3火+2非火) |
| 终极 | 焚天灭地(完整版) |
| 构建型 | 燃烧之心+可能1-2件泛用构建型 |

#### 突破瞬间

> 天灵根的设计文本写了"受克属性伤害+25%"，但怪物属性标注体系中未见Boss级水属性敌人。**这个负面特性在主线流程形同虚设**——除非未来补充水属性Boss。

## 三、跨系统联动断裂点

### 3.1 单元素Build的被动系统断供

```
火系被动=3个(火灵之心/烈焰之魂/不死鸟)
被动总槽=7个
缺口=4个

可选方案：
  A. 跨元素被动——但不触发跨系连携奖励(06 §5.3仅基于主动技能元素)
  B. 通用被动——但文档未区分"元素绑定被动"和"通用被动"

→ 7被动槽中仅43%与火修build相关
→ 被动系统对天灵根火修失去了"Build定义"功能
```

### 3.5 天灵根"负面特性"无触发

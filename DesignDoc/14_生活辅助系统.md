## 1. 炼器系统（装备锻造/强化）

```
锻造流程：
  1. 选择装备模板（部位+阶位）
  2. 投入主材料×5 + 辅料×3
  3. 选择附加灵石（可提升品质概率）：
     - 无灵石：白色60%/绿色30%/蓝色10%
     - 下品灵石：白色30%/绿色40%/蓝色25%/紫色5%
     - 中品灵石：绿色30%/蓝色40%/紫色25%/金色5%
     - 上品灵石：蓝色30%/紫色40%/金色25%/暗金5%
  4. 锻造完成，获得随机词条装备
  5. 可选择"重铸"（消耗材料重新随机词条，保留品质）

锻造等级：
  - Lv1-5：可锻造1-2阶装备
  - Lv6-10：可锻造3-4阶装备
  - Lv11-15：可锻造5-6阶装备
  - Lv16-20：可锻造7-9阶装备
  - 每级提升：品质概率+1%、词条最小值+1%
```

## 2. 法宝炼制（金丹期解锁，9号槽位）

### 2.1 法宝概述

法宝是金丹期解锁的第9个装备槽位，拥有独立的**主动技能**和**成长线**，是战斗中扭转战局的核心道具。

### 2.2 法宝获取：炼制流程

```
1. 获取法宝图纸：
   - Boss掉落(各Boss有专属图纸掉落池，掉率15%)
   - 神秘商人(每周刷新2-3张随机图纸)
   - 宗门商店(宗门贡献兑换)
   - 活动秘境(限时图纸)

2. 收集炼制材料：
   - 主材：对应品质矿石（紫色=赤金×20/金色=秘银×30/暗金=天外陨铁×40/红色=仙金×50）
   - 核心：妖兽内丹×5（品质≥法宝品质）
   - 灵石：紫色5000/金色15000/暗金40000/红色100000

3. 炼制（金丹期后在洞府炼器室进行）：
   - 基础成功率：紫色60%/金色40%/暗金20%/红色8%
   - 灵石加持：每投入1000灵石+1%成功率(红色每5000+1%)
   - 上限：紫色90%/金色75%/暗金55%/红色30%
   - 炼制时间：紫色1h/金色4h/暗金12h/红色48h（可用灵石加速）
   - 失败：材料全损，图纸保留
```

### 2.3 法宝成长线

```
法宝等级（独立于角色，消耗灵石+法宝碎片升级）：
  Lv1-10：每级消耗灵石×500+法宝碎片×2
  Lv11-20：每级消耗灵石×2000+法宝碎片×5
  Lv21-30(满级)：每级消耗灵石×8000+法宝碎片×10
  
  每5级解锁法宝技能效果强化
  满级解锁"法宝真名"——技能效果翻倍

法宝技能熟练度：
  - 使用法宝技能积累熟练度
  - 熟练度等级提升技能伤害/效果(每级+5%)
  - 最高Lv20（+100%效果）

法宝共鸣（与装备联动）：
  共鸣条件：装备与法宝同属性/同品质/同套装
  共鸣等级：
    1星：1个共鸣条件 → 共鸣效果+50%
    2星：2个共鸣条件 → 共鸣效果+100%
    3星：3个共鸣条件全满足 → 额外解锁隐藏共鸣技能
```

## 2B. 本命法宝（元婴期解锁，10号槽位）

### 2B.1 概述

本命法宝是元婴期解锁的终极装备槽位——**角色绑定、不可交易、不可掉落**，与角色灵魂绑定。它是唯一拥有**被动+主动双技能**的装备，且成长线贯穿终局。

### 2B.2 本命法宝觉醒

```
觉醒条件（元婴期Lv61自动触发任务）：
  1. 任务「本命觉醒」：前往上古遗迹，寻找本命法宝胚胎
  2. 选择本命法宝形态（五选一，不可更改）：
     ├── 本命飞剑 — 攻击向（ATK+AP加成+单体斩杀主动）
     ├── 本命灵珠 — 法术向（AP+MP加成+全屏AOE主动）
     ├── 本命宝甲 — 防御向（DEF+HP加成+全队无敌主动）
     ├── 本命灵炉 — 辅助向（全属性+炼丹/炼器加成+全队回复主动）
     └── 本命魂灯 — 特殊向（SPD+CRIT加成+时停主动）
  3. 消耗材料觉醒：元婴级内丹×3 + 灵晶×50 + 灵石×100000
  4. 觉醒后获得1级本命法宝
```

### 2B.3 本命法宝成长（独立等级1-100）

```
等级提升：
  - 消耗「本命精华」（Boss掉落/分解传说装备/活动）
  - Lv1-30：每级消耗本命精华×1
  - Lv31-60：每级消耗本命精华×3
  - Lv61-90：每级消耗本命精华×6
  - Lv91-100：每级消耗本命精华×10
  
  总计满级消耗：约300个本命精华
  Boss掉落：每次3-8个(元婴+)/1-3个(金丹-)
  预计满级时间：正常游玩约40-60小时

每10级解锁新能力：
  Lv10：被动技能效果+50%
  Lv20：主动技能解锁第二段效果
  Lv30：共鸣槽+1（可与另一件法宝共鸣）
  Lv40：被动技能追加新效果
  Lv50：主动技能CD-30%
  Lv60：全属性+10%
  Lv70：解锁隐藏被动（形态专属）
  Lv80：主动技能可使用2次/场
  Lv90：共鸣全开（3星无条件）
  Lv100(满级)：本命真名觉醒——外观变化+技能终极强化
```

## 4. 采药系统

```
采药机制：
  - 野外分布草药采集点
  - 采集需要"采药技能等级"≥草药需求等级
  - 采集成功获得草药×1-3（数量受技能等级和秘术影响）

  Lv1-5：可采集1-2阶草药
  Lv6-10：可采集3-4阶草药
  Lv11-15：可采集5-6阶草药
  Lv16-20：可采集7-9阶草药

药田系统（洞府内置）：
  - 可在洞府种植已获得的草药
  - 种植时间=野外刷新时间×0.7（洞府灵气加速，v1.1从×0.5提升）

  - 药田格数：初始6格，洞府升级扩展至16格（v1.1初始格数从4提升）

## 5. 灵兽系统（辅助战斗+探索）

### 5.1 灵兽获取

```
驯服流程：
  1. 野外击败妖兽后，低概率出现"可驯服"标记
  2. 使用御兽符进行驯服（商店购买/炼丹制作/任务奖励）
  3. 驯服成功率=基础概率×御兽符品质×灵兽稀有度修正
  
  基础概率：
    普通妖兽：40%  稀有妖兽：20%  史诗妖兽：10%  传说妖兽：5%
  
  御兽符品质：
    初级御兽符：×1.0（灵石商店500/个）
    中级御兽符：×1.5（炼丹制作/宗门商店1000贡献/个）
    高级御兽符：×2.0（Boss掉落/灵石商店 2000灵石/个）
  
  降服失败：
    妖兽逃跑（50%）/ 妖兽暴怒再次战斗（50%）
    妖兽不会死亡，可再次尝试

可驯服妖兽出现概率：
  普通妖兽击杀后：2% 出现可驯服版
  精英妖兽击杀后：5%
  稀有妖兽击杀后：15%
  Boss：不可驯服
```

### 5.2 灵兽成长

```
灵兽等级：
  - 等级上限=主人当前等级
  - 出战灵兽自动获得战斗经验（主人经验的50%）
  - 不出战灵兽可使用"灵兽丹"升级（炼丹制作）

灵兽进化（每个灵兽2次进化机会）：
  进化条件：
    第1次进化：灵兽等级≥30 + 妖兽内丹×5 + 灵石×10000
    第2次进化：灵兽等级≥60 + 对应传说内丹×1 + 灵石×50000
  
  进化效果：
    - 外观从幼体→成年体→完全体变化
    - 属性继承比例+10%/次（50%→60%→70%）
    - 解锁新技能（每次进化解锁1个新技能）
    - 技能效果+25%/次

灵兽技能（每只1-3个）：
  主动技能：战斗中自动释放（有独立CD，不受角色控制）
  被动技能：常驻生效
  羁绊技能：与主人灵根/功法共鸣时激活（需满足特定条件）
```

### 5.4 灵兽出战规则

```
出战限制：
  - 最多携带2只灵兽出战
  - 战斗中可切换（切换CD 30s，切换时灵兽离场+新灵兽登场）
  - 灵兽死亡后本场战斗不可再次出战（可用"还魂丹"复活）

灵兽AI（简化版）：
  攻击型：优先攻击主人当前目标，使用技能CD好了就放
  防御型：优先替主人承受伤害，技能在主人HP<50%或自身HP<30%时释放
  辅助型：技能CD好了就放（治疗/Buff），目标优先级=主人>自己>另一只灵兽
  特殊型：探索能力常驻，战斗中按攻击型AI行动

## 7. 药田系统量化

```
药田基础参数（v1.1调整）：
  初始格数：6格（洞府升级至5级→16格）
  生长速度：野外刷新时间×0.7（洞府灵气加速）
  种植限制：仅可种植已采集过的草药

灵石加速公式：
  加速后剩余时间 = 原剩余时间 × (1 - 加速比例)
  加速比例 = 投入灵石 / (原剩余秒数 × 10)
  例：原剩余2h=7200s，投入720灵石→加速比例=720/(7200×10)=1%→剩余=7128s
      投入10000灵石→加速比例=10000/72000≈14%→剩余≈6192s
      投入100000灵石→加速比例=100000/72000≈100%→立即成熟
  → 灵石加速设计的边际效用递减，鼓励自然等待或大量投入

收获规则：
  - 成熟后24h内不收获→草药枯萎（品质降1级）
  - 收获时低概率获得种子（可减少下次种植时间20%）
  - 药田满级(16格)+全种同种草药→触发"药田共鸣"：收获量+20%
```

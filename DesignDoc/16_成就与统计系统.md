# 16 — 成就与统计系统

---

## 1. 成就系统

### 成就分类（总计约150+成就）

#### 战斗成就（40+）

- 首次击杀Boss（每个主线Boss独立成就，共10个）
- 首次击杀区域Boss（每个区域Boss独立成就，共10个）
- 首次击杀隐藏Boss（每个隐藏Boss独立成就，共6个）
- 单次战斗伤害超过X
- 无伤击败Boss（主线/区域/隐藏分别计算）
- 击败高于自身10级的怪物
- 一场战斗触发10次暴击
- 利用元素反应击杀100个敌人
- Boss Rush模式通关
- 爬塔100层通关
- 爬塔100层S评价

#### 收集成就（30+）

- 收集X件蓝色/紫色/金色/暗金/红色装备
- 收集构建型装备（每件独立成就，共12件）
- 集齐所有12件构建型装备——称号「造物主」+全属性+10%
- 收集整套X阶套装
- 装备图鉴收集率达X%
- 怪物图鉴收集率达X%
- 收集所有功法（全功法收集）
- 收集所有丹方
- 拥有100万灵石
- 集齐所有灵兽（14只全收集）——称号「万兽之主」

#### 探索成就（20+）

- 解锁所有地图区域
- 发现所有隐藏洞穴
- 开启X个宝箱
- 找到X个隐藏NPC
- 发现传送阵
- 完成全部奇遇事件
- 踏遍世界每一个角落

#### 养成成就（30+）

- 达到每个境界（每个境界独立成就）
- 某件装备强化至+25
- 锻造出金色品质装备
- 炼丹暴击（一次产出5颗丹药）
- 功法参悟至9层圆满
- 灵兽进化至最终形态
- 全技能满级
- 全生活技能满级

#### 特殊成就（15+）

- 死亡X次（不屈）
- 灵石从未超过100（清贫修仙）
- 全程不使用丹药通关（苦修者）
- 使用五灵根角色达到化神期（逆天改命）
- 发现所有结局
- 游戏时间超过100小时（修仙达人）

#### 成就奖励

- 成就点数（用于兑换专属奖励）
- 专属称号（带属性加成）
- 专属外观/时装
- 稀有材料/道具
- 隐藏功法/技能

## 2. 统计系统

### 战斗统计

- 总击杀数：按怪物类型分类
- 总战斗次数
- 最高单体伤害
- 最高暴击伤害
- Boss击杀数（按Boss分类）
- Boss无伤通关次数
- 死亡次数
- 逃跑次数
- 最快Boss击杀时间
- 元素反应触发次数
- 各技能使用次数

### 探索统计

- 总步数/移动距离
- 访问区域数
- 宝箱开启数
- 隐藏发现数
- 传送使用次数
- 草药采集数（按种类）
- 矿石采集数（按种类）
- NPC对话次数

### 养成统计

- 总经验获得
- 总灵石获得/消耗
- 总金币获得/消耗
- 装备获得数（按品质）
- 装备分解数
- 构建型装备获得数（按件统计）
- 强化总次数/成功次数
- 炼丹总次数/成功次数/暴击次数
- 锻造总次数
- 功法参悟次数
- 法宝炼制次数/成功次数
- 本命法宝等级
- 灵兽收集数/进化数
- 灵兽出战总场次
- 药田收获总次数

### 通关评价（化神期通关后）

```
总评分：S/A/B/C/D

评价维度：
  ├── 战斗评分（击杀数/Boss速度/无伤率）
  ├── 收集评分（图鉴完成率/装备收集率）
  ├── 探索评分（地图解锁率/隐藏发现率）
  ├── 养成评分（境界速度/技能功法完成度）
  └── 特殊加成（使用低灵根通关/不使用丹药等挑战）

评价奖励：S级解锁NG+（New Game+，继承部分属性重新开始）
```

## 3. New Game+（二周目）

```
NG+机制（通关后解锁）：

继承内容：
  ├── 图鉴收集进度（100%继承）
  ├── 生活技能等级（100%继承）
  ├── 成就系统（100%继承）
  ├── 外观/时装（100%继承）
  └── 部分灵石/金币（继承30%）

不继承内容：
  ├── 角色等级（重置为1级）
  ├── 装备（清空，但保留图鉴外观）
  ├── 功法/技能（清空）
  └── 任务进度（重置）

NG+特殊内容：
  ├── 解锁更高难度"地狱模式"
  ├── 解锁隐藏灵根"混沌灵根"（全新修炼体验）
  ├── 部分Boss新增技能/阶段
  ├── 全新隐藏Boss
  ├── 新增"轮回"装备系列（上一世暗金+装备保留词条+启灵等级，散落世界待寻回）
  ├── 构建型装备传承：上一世持有的构建型装备，NG+中可在对应Boss处重新获得"轮回版"（基础属性+20%）
  └── 解锁真·隐藏结局
```

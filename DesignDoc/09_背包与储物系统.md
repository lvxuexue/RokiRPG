# 09 — 背包与储物系统

---

## 1. 存储架构

```
存储体系：
├── 随身背包（基础50格，可扩展至200格）
│   ├── 装备页签（按部位/品质筛选）
│   ├── 消耗品页签（丹药/材料/道具）
│   ├── 任务物品页签（不可丢弃）
│   └── 功法/技能书页签
│
├── 仓库存储（洞府/宗门，基础100格，可扩展至500格）
│   ├── 自动堆叠同类材料（上限999）
│   ├── 装备独立存储（不堆叠）
│   └── 跨存档共享仓库槽位（付费功能）
│
└── 快捷栏（战斗中使用，6格）
    ├── 丹药快捷使用
    └── 道具快捷使用
```

---

## 2. 背包功能

| 功能 | 说明 |
|------|------|
| 自动整理 | 按品质/类型/等级自动排序 |
| 一键分解 | 选择品质范围，自动分解装备为材料 |
| 锁定物品 | 锁定后不可出售/分解 |
| 批量出售 | 选择品质/类型，批量出售给商店 |
| 搜索筛选 | 按名称、品质、类型、等级范围筛选 |
| 装备对比 | 选中装备时显示与当前装备的属性差异 |

## 3. 背包扩展

| 扩展方式 | 增加格数 | 消耗 |
|----------|----------|------|
| 灵石扩展 | +10格 | 灵石递增（100→200→400→...） |
| 储物袋（道具） | +20格 | 掉落/商店购买 |
| 乾坤袋（稀有） | +50格 | 活动/灵石商店 8000灵石 |
| 须弥戒指（传说） | +100格 | 灵石商店 20000灵石 |

## 4. 构建型装备的背包特殊处理

拥有 `uniqueEffect` 的装备（详见 `03_装备系统.md` §11）在背包中享受特殊待遇：

| 特性 | 说明 |
|------|------|
| 专属边框 | 装备图标带金色脉动边框（与普通金色装备区分） |
| 不可一键分解 | 一键分解时自动跳过（需手动确认分解） |
| 专属页签 | 背包新增"至宝"页签，仅显示构建型装备 |
| 锁定保护 | 获得时自动锁定（可手动解锁） |
| 获得动画 | 掉落时全屏特殊光效+物品栏高亮提示 |

## 5. 装备预设系统

玩家可保存最多 5 套装备方案，一键切换：

```
预设槽位（5个）：
  预设1：「火系输出」— 燃烧之心 + 烈焰战甲3件 + 火伤戒指×2
  预设2：「冰系控制」— 冰脉护符 + 寒冰法袍3件 + 冰伤戒指×2
  预设3：「Boss讨伐」— 诛仙剑阵(法宝) + 破军战甲4件 + 对Boss项链
  预设4：「探索farm」— 天眼通头 + 移速鞋 + 掉落率戒指
  预设5：「渡劫专精」— 全抗装备 + 雷抗饰品

切换条件：
  - 所有预设装备必须在背包或仓库中
  - 切换CD：无（非战斗状态）/ 战斗中不可切换
  - 切换时自动对比并提示缺失装备
```

# 06 技能系统 — 丰富度评估与全流程模拟

## 一、丰富度多维度评估

### 1.1 评分总览

| 维度 | 评分 | 说明 |
|------|:----:|------|
| 技能总量 | ★★★☆☆ | 宣称120+，实际列出约67个，缺口明显 |
| 元素覆盖 | ★★★★☆ | 9系元素（金木水火土+雷冰暗光），五行最深 |
| 品质梯度 | ★★★★★ | 7级品质×倍率递增×变异分支数，层次清晰 |
| 槽位节奏 | ★★☆☆☆ | 初始3槽太少，终极技解锁过晚（金丹期） |
| Build多样性 | ★★★☆☆ | 有变异+连携框架，但跨系build支持弱 |
| 被动系统 | ★★☆☆☆ | 仅13个被动列出，7槽位严重填不满 |
| 变异系统 | ★★☆☆☆ | 仅7个技能有变异，覆盖不足 |
| 技能获取 | ★★★☆☆ | 7种途径但多数模糊（"奇遇""隐藏"无具体指引） |
| 升级经济 | ★★★☆☆ | 消耗清晰但技能点获取率未验证 |
| 数据模型 | ★★★★★ | 完整可落地的数据结构 |

**综合评分：3.0/5 — 五行主动技能体系较完整，但被动/变异/特殊属性是三个主要缺口**

### 1.2 技能实际统计（与宣称对比）

```
宣称：约120+技能

实际列出：
  金系：8主动 + 3被动 + 1终极 = 12
  木系：8主动 + 3被动 + 1终极 = 12
  水系：7主动 + 2被动 + 1终极 = 10
  火系：7主动 + 3被动 + 1终极 = 11
  土系：7主动 + 2被动 + 1终极 = 10
  雷系：2主动 + 0被动 + 1终极 = 3
  冰系(独立)：2主动 + 0被动 + 1终极 = 3
  暗系：2主动 + 0被动 + 1终极 = 3
  光系：2主动 + 0被动 + 1终极 = 3
  ────────────────────────────
  总计：约67个（vs 宣称120+，缺口53个）

缺口分析：
  - 雷/冰/暗/光每系仅3个技能（2主动+1终极），严重不足
  - 被动技能仅列出13个（需填满7槽位×不同build≈至少30+）
  - 终极技能每个元素仅1个（5终极×1=5 + 特殊4=4，共9个 vs 宣称10+勉强达标）
```

### 1.3 槽位解锁节奏问题

```
主动技能槽：
  Lv1-20：  3槽 □□□           — 炼气全期只有3个技能可用
  Lv21-40： 4槽 □□□□          — 筑基解锁第4槽
  Lv41-60： 5槽 □□□□□         — 金丹解锁第5槽
  Lv61-100：6槽 □□□□□□        — 元婴解锁第6槽

问题：炼气期前期（Lv1-15）3个主动槽只能放白/绿/蓝技能
     对应火系Lv1-15只有：火球术(白Lv1)+烈焰风暴(绿Lv10)=2个火技
     如果纯火build → 3槽都填不满！必须混搭其他元素
     
被动技能槽：
  Lv1/Lv15/Lv30/Lv45/Lv60/Lv75/Lv90 = 7槽
  实际列出被动仅13个（7元素×约2个），
  纯单元素build无法填满7个被动槽

终极技能槽：
  Lv41（金丹）解锁第1个终极槽 → 炼气+筑基全期（Lv1-40）没有终极技
  Lv81（化神）解锁第2个终极槽 → 第2个终极槽几乎没有使用场景（仅Lv81-100）
```

## 二、全流程模拟

### 2.1 炼气期（Lv1-20）技能体验

```
Lv1 — 初始状态：
  槽位：3主动 + 1被动
  技能点：0（初始无技能点）
  可学：火球术(白)、金刃术(白)、水弹术(白)、地刺术(白)、藤蔓术(白)
  ⚠️ 需要先获得技能点才能学技能！初始无技能点=只有普攻可用

Lv1-5 — 首次升级后：
  获得5技能点（5级×1点）
  学习：火球术Lv1(1点)+金刃术Lv1(1点)=2点剩余
  装备：火球术(CD 2.5s) + 金刃术(CD 2s) + 普攻
  战斗循环：火球 → 金刃 → 普攻×N → 循环
  ⚠️ 白技能伤害倍率仅150-180%，与普攻(100%)差距不大
     没有AOE、控制、回复——战斗策略=无脑按

Lv5-10 — 解锁绿色技能：
  获得更多技能点（累计5-10点）
  学习：烈焰风暴(绿Lv10需等待) / 回春术(绿Lv5) / 冰封术(绿Lv8)
  ⚠️ 绿色技能需要等级解锁但玩家可能没有对应属性灵石学习
     灵石获取 0-5级只有少量（约200-500灵石），学不了几个技能

Lv10 — 3槽填满：
  典型配置：火球术(白Lv2) + 烈焰风暴(绿Lv1) + 回春术(绿Lv1)
  被动：金灵附体(蓝) 或 火灵之心(绿)
  ⚠️ 被动仅1槽，选了火灵就没金灵，Build开始锁定
     此时无法更换被动（没有洗点机制提到）

Lv15-20 — 解锁蓝色技能：
  火神附体(Lv20)、穿心剑(Lv25)、雷击术(Lv15)等陆续解锁
  技能点累计15-20点，可升满1-2个技能
  ⚠️ 技能升级消耗11点/满级，20级时只能满级约1个技能
     变异系统要到Lv5满级才能体验→炼气全期基本与变异无关

炼气期总结：
  体验平淡：3个技能循环20级，90%时间在用1-2个白技能
  技能点稀缺：20级仅20技能点，1个满级技能就要11点
  被动单一：1槽用20级
  终极技：完全不存在的概念（金丹才有）
  评分：★★☆☆☆
```

### 2.2 筑基期（Lv21-40）技能体验

```
Lv21 — 第4主动槽解锁：
  4主动+2被动（Lv15第2被动）
  技能点累计：约30-40点

  典型Build（火系为主）：
    主动：火球术(Lv4) + 烈焰风暴(Lv3) + 火神附体(Lv2) + 回春术(Lv2)
    被动：火灵之心 + 烈焰之魂(紫Lv?需掉落)
    ⚠️ 前3个火技已经占满3槽，第4槽被迫上非火技能
    ⚠️ 火系只有3个主动技可用(Lv1-20区间)，Build深度不够

Lv25-35 — 紫色技能解锁：
  穿心剑(Lv25)、天火燎原(Lv28)、万物生长(Lv32)、重力术(Lv33)
  技能点累计40-55点，可满级约3-4个技能
  开始体验技能变异（第一个Lv5技能此时才出现）

  ⚠️ 变异体验来得太晚——玩家已经玩了约10-15小时

Lv35-40 — 关键金色技能解锁前夜：
  陨石术(Lv36)、毒爆术(Lv38)、冰天雪地(Lv40)
  ⚠️ 但需要找到技能书/奇遇才能学（不掉落不能直接解锁）
     如果运气差→只能用紫技过筑基Boss

筑基期总结：
  4槽让战斗策略感提升，但单元素Build技能不足
  变异系统开始体验（约第15小时），但仅限少数技能
  被动2槽仍然不够用
  评分：★★★☆☆
```

### 2.3 金丹期（Lv41-60）技能体验

```
Lv41 — 第5主动槽+第1终极槽解锁：
  这是技能系统的转折点！

  典型Build（火系完成体）：
    主动：火球术(Lv5变异) + 烈焰风暴(Lv5变异) + 火神附体(Lv4) + 
          天火燎原(Lv5变异) + 凤凰涅槃(Lv54待解锁)/陨石术(Lv5)
    终极：焚天灭地(Lv50)
    被动：火灵之心 + 烈焰之魂 + 不死鸟(金)

  ⚠️ 火系仍只有7个主动技，其中凤凰涅槃是Lv54才解锁
     5槽在Lv41-54之间用4个火技+1个混搭技能

Lv50 — 终极技能首体验：
  焚天灭地：全MP消耗 + 1场1次
  第一次在Boss战中使用终极技——这是游戏的"高潮时刻"
  ⚠️ 但终极技CD由"每场1次"限制，farm日常时舍不得用

金丹期总结：
  技能系统真正"成型"（5主动+3被动+1终极=9技能）
  元素共鸣开始发力（同系5连触发+30%元素伤害）
  但被动仍然不够丰富（3槽×13可选=每个元素约2个可选被动）
  评分：★★★★☆
```

### 2.4 元婴期-化神期（Lv61-100）

```
Lv61 — 第6主动槽（满槽）：
  6主动+5被动+1终极（化神后+第2终极）
  
  ⚠️ 6主动槽填满需要6个同元素技能
     火系仅7个可选（含Lv54凤凰涅槃刚解锁）→ 几乎无选择余地
     金系仅8个可选 → 勉强填满
     木系仅8个可选 → 勉强填满
     暗系仅3个可选 → 完全无法纯暗Build

  ⚠️ 7被动槽需要7个被动技能
     当前仅列出13个被动（5元素×2-3个），单元素仅2-3个
     → 纯元素Build只能填3/7被动槽
     → 被"强制混搭"被动技能

Lv81 — 第2终极槽：
  但此时仅有9个终极技可选（5元素+雷冰暗光各1）
  双终极Build需要不同元素的终极技（同元素只有1个）
  → 终极技缺乏选择空间
```

## 三、发现的问题

### 🔴 致命问题

#### 1. 技能数量严重不达标

```
宣称120+技能，实际列出67个（达成率56%）

缺口最大处：
  - 被动技能：需≈35个（7槽×5build），实际仅13个，缺口22个
  - 雷/冰/暗/光主动技能：每系仅3个(含终极)，各需补4-6个
  - 终极技能：虽有9个但同元素无选择，需每元素至少2个终极

影响：Build深度严重不足，"纯元素Build"在数学上不可能
```

#### 2. 初期体验空洞

```
Lv1-10（前1小时）：
  - 仅3个主动槽，只能放2个白技+1绿技
  - 战斗=两个技能轮流按+普攻等CD
  - 无AOE、无控制、无回复（除非特意学回春术）
  - 技能点稀缺到"学了不敢升级"

→ 前1小时的技能体验=几乎无体验
→ 与暗黑Like"从Lv1就有技能连招"的设计理念矛盾
```

#### 3. 被动系统断裂

```
7个被动槽位 vs 13个被动技能（且分散在5元素+
特殊属性）

单元素Build仅能填满2-3/7槽
→ 被动槽不是"Build选择"而是"有什么用什么"
→ 失去了被动系统的Build定义功能
```

### 🟡 严重问题

#### 4. 变异覆盖率不足

```
列出67个技能中仅7个有变异描述（覆盖率10%）
每个变异仅A/B二选一

缺失变异的关键技能：
  - 所有终极技能（无变异）
  - 所有被动技能（无变异）
  - 所有雷/冰/暗/光技能（无变异）
```

#### 5. 终极技解锁过晚

```
第一个终极技：金丹期Lv41（约20-25小时游玩）
→ 玩家在游戏近一半时间内完全不知"终极技"存在
→ 第一个终极技体验被推迟到第20+小时

建议：筑基期Lv30解锁第1个（弱化版）终极技
```

#### 6. 跨元素Build无支持

```
当前设计以"单元素Build"为核心：
  - 同系连携（鼓励连续同元素）
  - 功法共鸣（主修+副战同属性奖励）

但单元素Build在技能数量上不成立（见问题1）
→ 玩家被迫混搭，但混搭没有奖励机制
→ 需要"双元素Build""三元素Build"的专属加成
```

### 🟢 次要问题

#### 7. 技能点获取率未验证

```
每级获得1技能点 × 100级 = 100技能点
满级1个技能需11点
100点可满级约9个技能

但玩家需要填充：6主动+7被动+2终极=15个技能
→ 只能满级9/15=60%的技能
→ 数学上"全满级"不可能

但这可能是设计意图（选择性地满级技能）
只是需求在文档中没有明确说明
```

#### 8. 技能重置机制缺失

```
无"洗技能点"的机制描述
选择了变异后不可更改
→ 试错成本极高
→ 玩家不敢尝试冷门技能变异
```

## 四、改进建议

| 优先级 | 问题 | 建议 |
|--------|------|------|
| P0 | 技能数量不足 | 补约55个技能：被动+22、雷/冰/暗/光主动各+4-6、每元素第2终极+5 |
| P0 | 初期体验空洞 | Lv1赠送3个白技能(已学会)+50初始技能点；初始主动槽增至4个 |
| P0 | 被动系统断裂 | 每元素补充3-4个被动（扩展至约35个被动可选池） |
| P1 | 变异覆盖率 | 扩展至所有技能均有变异（至少20个技能×2变异=40种） |
| P1 | 终极技解锁 | 筑基Lv30解锁第1个弱化终极（50%效果），金丹解锁完整版 |
| P1 | 跨元素Build | 新增"双元素""三元素"连携奖励机制 |
| P2 | 技能重置 | 新增洗技能点丹方（或灵石重置，费用递增） |
| P2 | 技能点透明化 | 明确说明"选择性满级"的设计意图 |
